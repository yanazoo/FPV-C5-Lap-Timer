<a name="日本語"></a>

## 日本語

### 変更

- **Web 書き込みページ**（https://yanazoo.github.io/FPV-C5-Lap-Timer/）の「ELRS-NETpack（XIAO ESP32-S3）」（通常 / タイマー流用）が、**[ELRS-NETpack v2.3.7](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.7)** になりました。クライアントモードで WiFi につなぐとき、全チャンネルを探して**電波が一番強い AP** につなぐようになりました（メッシュ WiFi・中継器で同じ SSID の AP が複数あるとき。FPV C5 Lap Timer と同じ動き）。v2.3.6 の QR ページの変更も含みます。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.9 と同じです（書き換え不要）。netpack の XIAO を使う場合は、ELRS-NETpack v2.3.7 に書き換えてください（netpack の「更新」ページ、または Web 書き込みページ）。

### 動作確認

- PC テストと、すべてのビルド（タイマー・受信機・netpack の通常版とタイマー流用版・ブリッジ 4 種）を CI で確認しました。

## English

### Changes

- The web flasher's "ELRS-NETpack (XIAO ESP32-S3)" (standard / timer's wiring) is now **[ELRS-NETpack v2.3.7](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.7)**: client mode joins the network's **strongest access point** (all-channel scan; a mesh or repeater), as FPV C5 Lap Timer does; v2.3.6's QR page included.

### Matching firmware

The timer (S3) firmware is the same as v2.3.9 (no update needed). With a netpack XIAO, update it to ELRS-NETpack v2.3.7.

### Verified

- PC tests and every build (timer, receiver, netpack standard and timerwiring, four bridges) in CI.
