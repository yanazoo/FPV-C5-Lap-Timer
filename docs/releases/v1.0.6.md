## 日本語

### 変更：スタートで「レディ」と読み上げ、言い終わってからカウントダウン

- スタートボタンを押すと「**レディ**」と読み上げます。これまでは「スタート」でした
- 「レディ」を**言い終わってから**、3・2・1 のカウントダウンが始まります
  - ゴーグルの ARM NOW と、ほかのブラウザのカウントダウンも、同じタイミングで始まります
- iPhone では、読み上げが終わったことが通知されない場合があります。そのときも、読み上げ中かどうかを見て判断します。押してから 2.5 秒以内には、必ずカウントダウンが始まります
- 音声が OFF のときや「ビープ音のみ」のときは、これまでどおり押してすぐにカウントダウンが始まります
- 一時停止からの再開（ストップ → スタート）では読み上げません

### 修正：CROSSING 表示でパイロット名が隠れる

ゲートを通過している間に出る「CROSSING」表示のせいで、レースカードのパイロット名が 1 文字まで縮んだり、見えなくなったりしていました。スマホと、PC の 8 列表示で起きていました。

- CROSSING 表示を、見出しの右端に重ねて出すようにしました。パイロット名は隠れません

### ドキュメント

- README（日本語・英語）に、Web UI の画面イメージを追加しました（レース PC／スマホ・設定・キャリブレーション）
- 初期設定値を表にまとめました。どれも公開用の既定値です

  - ホストモードのパスワード：`fpv-c5-lt`

  - netpack XIAO の設定用 AP：`ELRS-Netpack-Setup` / `elrs-netpack`

### 更新方法

v1.0.5 から更新する場合は、**Web UI** だけを書き込み直してください。ファームウェアは変わっていません。

```bash
git fetch && git checkout v1.0.6
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みのバイナリも添付しています。`fpv-c5-lap-timer-v1.0.6-xiao_esp32s3.zip` の中の `littlefs.bin` が Web UI です。

<a name="english"></a>

## English

### Changed: Start says "レディ" (ready), and the countdown follows it

- Start now says "**レディ**" instead of "スタート"
- The 3-2-1 countdown starts **once the call has been said**
  - The ARM NOW on the goggles and the countdown on the other browsers start at the same moment
- iOS often doesn't report when speech ends. The timer then watches whether speech is still playing, and the countdown always starts within 2.5 s of the press
- With voice off or set to beeps only, the countdown starts at once, as before
- Nothing is said when resuming a paused race

### Fixed: the CROSSING badge hid the pilot's name

While a pilot was in the gate, the "CROSSING" badge took room from the card header. The pilot's name shrank to a single letter or vanished, on phones and in the 8-column PC layout.

- The badge now sits over the right end of the header, so the pilot's name stays visible

### Documentation

- The README (Japanese and English) has screenshots of the web UI: the race tab on PC and phone, settings, and calibration
- It also has a table of the first-boot defaults. These are all public defaults:
  - host-mode SSID: `FPV-C5-LT`
  - host-mode password: `fpv-c5-lt`
  - URL: `http://20.0.0.1`
  - admin password: `admin`
  - netpack XIAO setup AP: `ELRS-Netpack-Setup` / `elrs-netpack`
