<a name="日本語"></a>

## 日本語

XIAO ESP32-S3 **Sense** の拡張ボードに付いているマイクを使えるようにしました。音の合図でスタートしたり、カウントダウン中のフライングを見つけたりできます。新しい使い方が加わったので、バージョンを 2.0.0 にしました。

### 追加：マイク（XIAO ESP32-S3 Sense の拡張ボード）

マイクが見つかったときだけ、**キャリブタブの一番下**に「🎤 マイク」の欄が出ます（拡張ボードが無いときは出ません）。パイロットのグラフと同じ形の音量グラフ（0〜100）に、閾値の線が重なって表示されるので、会場で音を出しながら調整できます。機能はどれも初期値 OFF です。

- **マイクでスタート**：レースをしていないとき（クリアした後）、緑の線を「スタートの検知時間」以上越える音が「**閾値越えカウント回数**」（1〜9 回、初期値 2 回、音と音の間は 0.8 秒以内）だけ続くと、スタートします。
  - 例：手を 2 回叩いてスタート ＝ 2 回・0.02 秒、笛やエアホーン 1 回でスタート ＝ 1 回・0.2 秒
  - 通常はスタートボタンと同じ流れです（スタートの待ち時間 → レディ → 3-2-1）。回数がちょうど同じときだけ反応します。
  - **即スタート**を ON にすると、待ち時間・レディ・3-2-1 を飛ばし、合図の音そのものを GO として計測を始めます（時計は、最後の音が鳴り始めた瞬間から）。
  - ストップ・クリアの後 5 秒は反応しません。
- **フライング検知**：ARM NOW から GO までの間に、赤の線を超える音（スロットルを上げたモーター音など）が「フライングの検知時間」だけ続くと、レースを止めて「フライングです。レースを中止します。」と読み上げ、カウントをクリアします。ゴーグルには FALSE START と出ます。
- **閾値越え 3 回でクリア**：ストップした後に、同じ条件の音が 3 回で、クリアボタンと同じようにクリアします（SD への保存も同じ）。
- マイクの設定は、設定情報のバックアップにも入ります。

### 追加：CPU 温度

- ヘッダーの C5・OSD のランプの横に、タイマー（ESP32-S3）のチップの温度を「CPU ○○℃」と表示します。チップ自身の熱が入るので、気温より 10〜20℃ほど高めに出ます。

### 画面の改善

- 黒っぽかったボタン（クリア、音声テスト、編集、ダウンロード、キャンセルなど）を、淡い灰色にしました。
- 一覧の削除ボタン（パイロット情報・SD のファイル）を、淡い赤にしました。確認ウィンドウの「削除する」などは赤のままです。
- キャリブレーションのグラフの閾値の線（緑・赤）を、太くはっきりさせました。
- 観戦画面のマークを「👥 観戦」にしました。iPhone の観戦画面で、「音声テスト」ボタンが中央に来るようにしました。
- SD タブの文を「SDカード検出済み — レース中は操作できません。」にしました。

### 更新方法

タイマーのファームウェアと Web UI の**両方**を書き込んでください。

```bash
git fetch && git checkout v2.0.0
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みのバイナリも添付しています。設定は引き継がれます（マイクの設定は初期値の OFF から始まります）。Web 画面が開けないときは、`uploadfs` をもう一度行ってください。

- 実機で確認しました。

## English

The microphone on the XIAO ESP32-S3 **Sense** board can now start races on a sound signal and catch false starts in the countdown. With this new way of running a race, the version moves to 2.0.0.

### New: microphone (XIAO ESP32-S3 Sense board)

Only when a microphone is found, a "🎤 マイク" section appears at the **bottom of the Calibration tab** (nothing without the Sense board): a loudness graph (0–100) like the pilots', with the thresholds as dashed lines, to set on site. Everything is off by default.

- **Start by sound**: with no race on (after Clear), sounds above the green line, each lasting at least the start detection time, the **set number of times** (1–9, default 2; at most 0.8 s apart) start the race.
  - For example two claps = 2 times, 0.02 s; one whistle or air horn = 1 time, 0.2 s.
  - Normally like the Start button (start delay → ready → 3-2-1), on an exact count only.
  - With **start now** (即スタート) on, the signal itself is GO: no delay, ready or 3-2-1; the clock runs from when the last sound began.
  - Not within 5 s of a stop or clear.
- **False start**: a sound above the red line (a quad throttling up) lasting the false-start detection time between ARM NOW and GO stops the race, announces "フライングです。レースを中止します。" and clears the count; the goggles show FALSE START.
- **Three to clear**: after a stop, three such sounds clear the race like the Clear button (saved to SD the same way).
- The microphone settings are part of the settings backup.

### New: CPU temperature

- The header shows the timer's (ESP32-S3) chip temperature next to the C5/OSD lamps, "CPU ○○℃". It reads 10–20 °C above the air around it.

### Screen

- Dark buttons (Clear, voice test, edit, download, Cancel...) are a light grey; list delete buttons (pilots, SD files) a muted red; dialog confirm buttons stay solid red.
- Calibration threshold lines (green, red) are thicker and solid.
- The spectator badge is "👥 観戦"; on an iPhone the spectator's voice test button is centred.
- The SD tab reads "SDカード検出済み — レース中は操作できません。".

### Updating

Flash **both** the timer's firmware and the web UI.

```bash
git fetch && git checkout v2.0.0
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

Prebuilt binaries are attached. Settings are kept (the microphone starts off). If the page does not open, run `uploadfs` again.
