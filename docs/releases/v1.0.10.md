## 日本語

### 新機能：SD タブで過去のレースを見返す

クリアして SD カードに保存したレースを、ブラウザーの **SD タブ**で見返せます。

- **📜 レース結果**：新しい順の一覧です。日時・優勝者・イベント名・人数・周回・最速ラップを表示します。
  - 最初の 10 件を自動で読み込み、「さらに 10 件」で続きを表示します。
  - 一度読んだレースはブラウザーが覚えるので、次からはすぐ表示されます。
- **レースをタップ**すると、「結果」と「グラフ」を切り替えて表示します。
  - **結果**：順位表（差つき）とラップ表です。各パイロットの最速ラップは緑で表示します。
  - **グラフ**：周ごとのラップタイムの推移と、安定度（平均とばらつき）です。凡例をタップすると表示・非表示を切り替えます。同じタイムで線が重なったときは、両方の色が見えるように描き、注記を出します。
- **👤 パイロット別**（押したときだけ）：全レースを集計し、出走数・1 位の回数・自己ベストと、最速ラップの推移を表示します。
  - 全ファイルを読むので、先に**件数とかかる時間の目安**を表示し、確認してから始めます。
  - 読み込み中は残り時間を表示し、途中で中止できます。

### 新機能：レースの日時と設定を記録

- タイマーには時計がないため、つないだブラウザーの時刻をタイマーに渡します。
- ファイル名にレースの開始日時が入ります（例：`race_012_20261108_1432.csv`）。
- CSV の 1 行目に、開始日時と設定（総周回数・順位の決め方・制限時間・イベント名）を記録します（`#FPVC5,...`）。
- 電源を入れてからブラウザーが一度もつながっていない間に保存したレースは、日時なし（`race_012.csv`）になり、一覧では「日時不明」と表示します。以前のファイルも同じ表示です。

### 新機能：SD カードのフォーマット

- 「📁 ファイル」の下の「⚠ その他の操作」を開くと、小さな「🧹 フォーマット…」ボタンがあります。
- SD カードのファイルをすべて削除します。管理者パスワードの再入力が必要です。
- レース中や、クリアしていないラップがあるときはできません。

### 修正：SD ログの「上書き」で新しいレースが消える

- **原因**：古いファイルを消して空いた番号を、新しいレースに使っていました。次の保存では、その「番号が一番小さい＝一番新しい」レースを消していました。
- **修正**：ファイル名の日時が一番古いものから消すようにしました（日時のないファイルは古い扱い）。番号は最後の番号の次を使い、999 の次は 000 に戻ります。

### 更新方法

**タイマー（ファームウェアと Web UI の両方）**を書き込み直してください。ブリッジと受信機は書き換え不要です。

```bash
git fetch && git checkout v1.0.10
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みのバイナリも添付しています。設定は引き継がれます。

## English

### New: look back at past races in the SD tab

Races saved on the SD card when you press Clear are shown in the browser's **SD tab**.

- **📜 Race results**: newest first, with date, winner, event, pilots, laps and best lap.
  - The first 10 are read automatically; "さらに 10 件" shows more.
  - A race read once is remembered by the browser and shows at once next time.
- **Tap a race** for **Results** (結果) or **Graph** (グラフ):
  - Results: the ranking (with gaps) and the lap table; each pilot's best lap in green.
  - Graph: lap times lap by lap and consistency (mean and spread); tap the legend to show or hide a pilot. Lines with the same times are drawn so both colours show, with a note.
- **👤 Per pilot** (パイロット別, on request): totals over every race (races, wins, personal best) and the best-lap trend.
  - It reads every file, so it first shows how many and **about how long that takes**.
  - While reading it shows the time left and can be stopped.

### New: the race's date and rules are recorded

- The timer has no clock; connected browsers pass theirs on.
- File names hold the race's start time (`race_012_20261108_1432.csv`).
- The first CSV line records the start time and rules (total laps, ranking, time limit, event): `#FPVC5,...`.
- A race saved before any browser connected since power-on has no date (`race_012.csv`) and shows as "日時不明" (unknown date), as do older files.

### New: format the SD card

- Under "📁 ファイル", open "⚠ その他の操作" for a small "🧹 フォーマット…" button.
- It deletes every file on the card; the admin password is asked again.
- Not during a race or with laps not yet cleared.

### Fixed: SD log "rotate" mode deleted the newest race

- **Cause**: the number freed by deleting an old file was given to the new race, which the next save then deleted as the "lowest number".
- **Fix**: the race with the oldest date in its file name is deleted (files without a date count as older). Numbers follow on from the last one, 999 -> 000.

```bash
pio run -e xiao_esp32s3 -t uploadfs
```

Prebuilt binaries are attached. Settings are kept.
