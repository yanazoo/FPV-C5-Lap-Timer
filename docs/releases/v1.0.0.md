<a name="日本語"></a>

## 日本語

XIAO ESP32-C5（FPVGate C5MK）で各パイロットの 5.8GHz VTX の電波を測り、XIAO ESP32-S3 でラップを計測して、ESP-NOW ブリッジ → ELRS バックパック経由で **HDZero ゴーグル**の OSD に表示するラップタイマーです。

> **ゴーグル OSD は HDZero ゴーグル（ELRS バックパック搭載）のみ対応**しています。それ以外のゴーグルでは OSD は表示されません（ラップ計測・Web UI・読み上げは使えます）。

### 主な機能

- **ゲート通過の検出**：C5 が 8 チャンネルの VTX の RSSI を各約 1 kHz で測定します。S3 はピーク時刻を通過時刻として、ラップを計算します。機体側のビーコンは不要です
- **ラップ計算**：ホールショット / 計測モード、クールダウン、一時停止・再開、ベストラップ、順位、総周回数での完走（完走後の通過は数えません）
- **ゴーグル OSD（HDZero のみ）**：RotorHazard 用 vrxc_elrs の表示を移植しました。ARM NOW → GO! → クロック・順位・ラップタイム・BEST → FINISHED! / LAND NOW! を表示します
  - 基本の構成は、**ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E）を S3 に UART で直結**する方法です（netpack の XIAO・WiFi 設定は不要）
  - 次の手段として、WiFi 接続（elrs-netpack の XIAO 経由）も使えます
  - パケットが落ちても表示が消えたり残ったりしないよう、全消去を使わずに行単位で書き込みます。表示を出すときは合計 3 回、消すときは合計 5 回送ります
- **Web UI**（スマホ対応）：レース・パイロット・キャリブレーション・SD・設定の画面。効果音・日本語読み上げ・管理者ログイン付きです
- **WiFi**：ホスト（アクセスポイント）／クライアント（ルーターに接続）を選べます。クライアントで接続できないときは、15 / 30 / 60 秒でホストに切り替わります
- **microSD**：レース結果の CSV 保存、パイロット情報のバックアップ・復元

書き込みは、ソースから PlatformIO で行う方法をおすすめします（手順は README の「セットアップ」）。

```bash
git clone --recurse-submodules --branch v1.0.0 https://github.com/yanazoo/FPV-C5-Lap-Timer.git
cd FPV-C5-Lap-Timer
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

## English

An FPV drone lap timer that times each pilot's own 5.8 GHz VTX: a XIAO ESP32-C5 running FPVGate C5MK measures the VTX signals, a XIAO ESP32-S3 detects gate passes and computes laps, and lap times are shown on the pilots' **HDZero** goggles through the ESP-NOW bridge and the goggles' ELRS backpack. No transponder on the quad.

> **The goggle OSD works with HDZero goggles (with an ELRS backpack) only.** Other goggles show no OSD; lap timing, the web UI and voice announcements still work.

### Features

- **Gate detection**: the C5 samples the RSSI of up to 8 VTX channels at about 1 kHz each; the S3 takes the peak time as the pass time
- **Laps**: holeshot or immediate start, cooldown, pause/resume, best lap, positions, total-laps finish (passes after finishing don't count)
- **Goggle OSD (HDZero only)**: a port of RotorHazard's vrxc_elrs: ARM NOW → GO! → clock, position, lap time, best lap → FINISHED! / LAND NOW!
  - base setup: the **ESP-NOW bridge (XIAO ESP32-C3 / Wrover-E) wired straight to the S3 over UART** (no netpack XIAO, no WiFi setup)
  - the next choice: over WiFi through the elrs-netpack XIAO
  - rows are written whole, never with a full-screen clear, so a lost packet neither blanks nor strands a row; draws are sent 3 times in all, clears 5 times
- **Web UI** (phone friendly): race, pilots, calibration, SD and settings, with sound effects, Japanese TTS and an admin login
- **WiFi**: host (own access point) or client (joins a router); a client that can't connect falls back to the access point after 15, 30 or 60 s
- **microSD**: race results as CSV, pilot list backup and restore

### Change these first

The defaults are public: **change the WiFi (host) password `fpv-c5-lt` and the admin password `admin` during setup**. New values are stored on the device only, never in the repository.

- S3, C5 and bridge builds checked in CI
