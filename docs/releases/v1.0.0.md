# FPV C5 Lap Timer v1.0.0 — 最初の安定版

XIAO ESP32-C5（FPVGate C5MK）で各パイロットの 5.8GHz VTX の電波を測り、XIAO ESP32-S3 でラップを計測して、ELRS バックパック経由でゴーグルの OSD に表示するラップタイマーです。

## 主な機能

- **ゲート通過の検出**：C5 が 8 チャンネルの VTX の RSSI を各約 1 kHz で測定します。S3 はピーク時刻を通過時刻として、ラップを計算します。機体側のビーコンは不要です
- **ラップ計算**：ホールショット / 計測モード、クールダウン、一時停止・再開、ベストラップ、順位、総周回数での完走（完走後の通過は数えません）
- **ゴーグル OSD**：RotorHazard 用 vrxc_elrs の表示を移植しました。ARM NOW → GO! → クロック・順位・ラップタイム・BEST → FINISHED! / LAND NOW! を表示します
  - 接続は WiFi（elrs-netpack の XIAO 経由）か UART 直結（ESP-NOW ブリッジ：Wrover-E / XIAO ESP32-C3）
  - パケットが落ちても表示が消えたり残ったりしないよう、全消去を使わずに行単位で書き込みます。表示を出すときは合計 3 回、消すときは合計 5 回送ります
- **Web UI**（スマホ対応）：レース・パイロット・キャリブレーション・SD・設定の画面。効果音・日本語読み上げ・管理者ログイン付きです
- **WiFi**：ホスト（アクセスポイント）／クライアント（ルーターに接続）を選べます。クライアントで接続できないときは、15 / 30 / 60 秒でホストに切り替わります
- **microSD**：レース結果の CSV 保存、パイロット情報のバックアップ・復元

## 対応するファームウェア

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | このリリース |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（サブモジュール `e62a635`） |
| ESP-NOW ブリッジ（Wrover-E / XIAO ESP32-C3） | [elrs-netpack v2.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.6) |
| RotorHazard で使う場合のプラグイン | [vrxc_elrs v1.1.7](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.7) |

## 添付ファイル

ビルド済みバイナリです（ZIP 内にブートローダー・パーティション・ファームウェア）。

- `fpv-c5-lap-timer-v1.0.0-xiao_esp32s3.zip`：タイマー（`littlefs.bin` は Web UI）
- `fpvgate-c5mk-v1.0.0-xiaoc5.zip`：C5 受信機
- `elrs-espnow-bridge-v1.0.0-esp32dev.zip` / `-xiao_esp32c3.zip`：ESP-NOW ブリッジ

書き込みは、ソースから PlatformIO で行う方法をおすすめします（手順は README の「セットアップ」）。

```bash
git clone --recurse-submodules --branch v1.0.0 https://github.com/yanazoo/FPV-C5-Lap-Timer.git
cd FPV-C5-Lap-Timer
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

## 初回に必ず変更してください

公開リポジトリに載っている既定値のため、**WiFi（ホスト）のパスワード `fpv-c5-lt` と管理者パスワード `admin` は、初期設定で必ず変更してください**。変更した値は本体にのみ保存され、リポジトリには含まれません。
