## 日本語

PlatformIO を使わずに、ファームを書き込んだり更新したりできるようにしました。

### 追加：Web 書き込みページ

- **https://yanazoo.github.io/FPV-C5-Lap-Timer/**
- PC の **Chrome / Edge** で開き、機器を USB でつないで「書き込む」を押すだけで書き込めます。PlatformIO も git も要りません。
- タイマー（XIAO ESP32-S3）・受信機（XIAO ESP32-C5）・ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E）の最新リリースを書き込めます。
- 書き込むのはファームと Web 画面の場所だけです。「デバイスを消去する（Erase device）」にチェックを入れなければ、WiFi・パスワード・パイロット情報などの設定は残ります。
- つながらないときは、BOOT ボタンを押したまま RESET（または USB を挿し直す）してから試してください。

### 追加：タイマーの画面からファームを更新

設定タブの「**⬆️ ファーム更新**」から、USB を使わずに更新できます。

- **ネットから**：クライアントモードでインターネットにつながっていれば、「🔍 最新版を確認」→「⬇️ vX.Y.Z に更新」で、タイマーが GitHub の最新リリースのファームと Web 画面をダウンロードして書き込み、再起動します。ダウンロードは GitHub の証明書を確かめて行います。
- **ファイルから**：リリースの zip の中の `firmware.bin` と `littlefs.bin`（Web 画面）を選んで書き込みます。ホストモード（ネットなし）でも使えます。
- 設定とパイロット情報は残ります。管理者だけが使え、レース中・ラップが残っている間は書き込めません。
- Web 画面の書き込みが途中で止まっても、ファームに入っている「復旧」ページが開くので、そこから書き直せます。
- システム情報に、リリース番号（例 `v2.2.1`）も出るようになりました。

### 改善

- README の冒頭に、書き込み・更新の URL（Web 書き込みページ・最新リリース）をまとめました。

### 対応するファームウェア

v2.2.0 から、受信機とブリッジは変わりません。

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | このリリース |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（サブモジュール `e62a635`。変更なし） |
| ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E） | [elrs-netpack v2.11](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.11)（変更なし） |
| netpack XIAO（WiFi で使う場合） | [elrs-netpack v2.10](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.10) 以降（変更なし） |
| RotorHazard で使う場合のプラグイン | [vrxc_elrs v1.1.9](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.9)（変更なし） |

### 更新方法

v2.2.0 以前のタイマーは、この版を一度、**Web 書き込みページ**か PlatformIO で書き込んでください（ファームと Web 画面の両方）。次の版からは、タイマーの画面の「ネットから更新」で更新できます。

```bash
git fetch && git checkout v2.2.1
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みのファイルも添付しています。設定とパイロット情報は引き継がれます。

### 動作確認

- PC テストはすべて合格し、S3・C5・ブリッジのビルドを CI で確認しました（新しいコードにコンパイルの警告はありません）。
- Web 書き込みページの書き込み位置は、各ファームのパーティション表から決め、設定の領域（NVS）に書かないことを PC で確かめました。
- ブラウザー（モック）で、ファーム更新の画面（確認・ネットから・ファイルから・違うファイルを断る）を確認しました。
- ネットからの更新と Web 書き込みページは、このリリースで公開されるため、実機ではこれから確認します。

## English

Firmware can now be flashed and updated without PlatformIO.

### New: web flasher

- **https://yanazoo.github.io/FPV-C5-Lap-Timer/**
- Open it in **Chrome or Edge** on a PC, plug the device in by USB and press "書き込む". No PlatformIO, no git.
- The latest release for the timer (XIAO ESP32-S3), the receiver (XIAO ESP32-C5) and the ESP-NOW bridge (XIAO ESP32-C3 / Wrover-E).
- Only the firmware and web UI regions are written: leave "Erase device" unticked and WiFi, passwords and pilots are kept.
- If the device isn't found, hold BOOT while pressing RESET (or replugging USB) and try again.

### New: update the timer from its own page

Settings → "**⬆️ ファーム更新**", no USB needed.

- **Online**: in client mode with internet, "🔍 最新版を確認" then "⬇️ vX.Y.Z に更新": the timer downloads the latest release's firmware and web UI from GitHub (certificates checked), writes them and restarts.
- **From files**: pick `firmware.bin` and `littlefs.bin` (web UI) from the release zip; works in host mode too.
- Settings and pilots are kept. Admin only; not during a race or with laps not cleared.
- If a web UI write is cut off, a rescue page built into the firmware lets you write it again.
- The system info also shows the release (e.g. `v2.2.1`).

### Improved

- The README starts with the flashing and update links (web flasher, latest release).

### Matching firmware

The receiver and the bridge are unchanged from v2.2.0.

| Device | Firmware |
|---|---|
| XIAO ESP32-S3 (timer) | this release |
| XIAO ESP32-C5 (receiver) | FPVGate C5MK (submodule `e62a635`, unchanged) |
| ESP-NOW bridge (XIAO ESP32-C3 / Wrover-E) | [elrs-netpack v2.11](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.11) (unchanged) |
| netpack XIAO (for WiFi) | [elrs-netpack v2.10](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.10) or later (unchanged) |
| RotorHazard plugin (if used) | [vrxc_elrs v1.1.9](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.9) (unchanged) |

### Updating

Flash a v2.2.0 or older timer with this release once, with the **web flasher** or PlatformIO (firmware and web UI). From the next release on, "online" on the timer's page does it.

```bash
git fetch && git checkout v2.2.1
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

Prebuilt files are attached. Settings and pilots are kept.

### Verified

- All PC tests pass; the S3, C5 and bridge builds were checked in CI (no compiler warnings in the new code).
- The web flasher's offsets come from each build's partition table; checked on the PC that the settings region (NVS) is never written.
- In a browser (mock): the update card (check, online, from files, a wrong file refused).
- The online update and the web flasher go live with this release; they are checked on real hardware next.
