# FPV C5 Lap Timer v2.3.6 — ELRS-NETpack v2.3.3 を Web 書き込みページに / ELRS-NETpack v2.3.3 on the web flasher

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

### 変更

- **Web 書き込みページ**（https://yanazoo.github.io/FPV-C5-Lap-Timer/）の「ELRS-NETpack（XIAO ESP32-S3）」（通常 / タイマー流用）が、**[ELRS-NETpack v2.3.3](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.3)** になりました。netpack の WiFi が、クライアントモード・設定用の WiFi も含めてすべて 20 MHz 幅になります（FPV C5 Lap Timer と同じ）。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.4 と同じです（書き換え不要）。netpack の XIAO を使う場合は、ELRS-NETpack v2.3.3 に書き換えてください（netpack の「更新」ページ、または Web 書き込みページ）。

### 動作確認

- PC テストと、すべてのビルド（タイマー・受信機・netpack の通常版とタイマー流用版・ブリッジ 4 種）を CI で確認しました。

## English

### Changes

- The web flasher's "ELRS-NETpack (XIAO ESP32-S3)" (standard / timer's wiring) is now **[ELRS-NETpack v2.3.3](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.3)**: every netpack WiFi is 20 MHz wide, client mode and the setup WiFi included (as FPV C5 Lap Timer).

### Matching firmware

The timer (S3) firmware is the same as v2.3.4 (no update needed). With a netpack XIAO, update it to ELRS-NETpack v2.3.3.

### Verified

- PC tests and every build (timer, receiver, netpack standard and timerwiring, four bridges) in CI.
