# FPV C5 Lap Timer v2.2.2 — 画面からのファーム更新（ネットから）の修正 / Fix for online updates from the timer's page

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

v2.2.1 で入れた「ネットから更新」が、実機で `GitHub に接続できませんでした（-1）` になる不具合を直しました。

### 修正

- **「🔍 最新版を確認」が失敗する**：GitHub のダウンロードは別のサーバーへ転送されますが、その転送先へつなぎ直すときに証明書の設定が外れ、`SSL - No CA Chain is set` で失敗していました。転送のたびに新しい接続を作るようにし、失敗したときは 3 回までやり直します。
- **証明書**：ファームに入れていた一部の証明書ではなく、ESP32 に組み込まれている全 CA の束（Mozilla と同じもの）で GitHub を確かめるようにしました。GitHub が証明書を変えても更新できます。
- **エラーの表示**：失敗したときに、どこで止まったか（名前の解決・時計合わせ・接続）と、通信の詳しい理由を画面に出すようにしました。

### 対応するファームウェア

v2.2.1 から、受信機とブリッジは変わりません。

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | このリリース |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（サブモジュール `e62a635`。変更なし） |
| ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E） | [elrs-netpack v2.11](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.11)（変更なし） |
| netpack XIAO（WiFi で使う場合） | [elrs-netpack v2.10](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.10) 以降（変更なし） |
| RotorHazard で使う場合のプラグイン | [vrxc_elrs v1.1.9](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.9)（変更なし） |

### 更新方法

v2.2.1 の「ネットから更新」はこの不具合で使えないため、この版は次のどれかで一度書き込んでください。次の版からは「ネットから更新」で更新できます。

- **タイマーの画面から**：設定タブ「⬆️ ファーム更新」→「ファイルから」で、このリリースの zip の中の `firmware.bin` と `littlefs.bin` を選んで書き込みます（USB 不要）。
- **Web 書き込みページ**：https://yanazoo.github.io/FPV-C5-Lap-Timer/ （PC の Chrome / Edge と USB）
- **PlatformIO**：

```bash
git fetch && git checkout v2.2.2
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

設定とパイロット情報は引き継がれます。

### 動作確認

- 実機（XIAO ESP32-S3、クライアントモード）で、「🔍 最新版を確認」が成功し、最新版（v2.2.1）を読めることを確かめました。
- PC テストはすべて合格し、S3・C5・ブリッジのビルドを CI で確認しました。
- ネットからのファームと Web 画面の書き込み（「⬇️ 更新」）は、次の版が出たときに実機で確かめます。

<a name="english"></a>

## English

The "online" update added in v2.2.1 failed on real hardware with `GitHub に接続できませんでした（-1）`. This release fixes it.

### Fixed

- **"🔍 最新版を確認" failed**: GitHub's downloads redirect to another server. When the timer reconnected to that server, its certificate setting was lost, and the connection failed with `SSL - No CA Chain is set`. Each redirect now uses a new connection, and a failed attempt is retried up to 3 times.
- **Certificates**: GitHub is now checked against the full CA store built into the ESP32 (the same as Mozilla's), not the few certificates the firmware carried. Updates keep working if GitHub changes certificates.
- **Error messages**: a failure now says where it stopped (name lookup, clock, connection) and gives the TLS reason.

### Matching firmware

The receiver and the bridge are unchanged from v2.2.1.

| Device | Firmware |
|---|---|
| XIAO ESP32-S3 (timer) | this release |
| XIAO ESP32-C5 (receiver) | FPVGate C5MK (submodule `e62a635`, unchanged) |
| ESP-NOW bridge (XIAO ESP32-C3 / Wrover-E) | [elrs-netpack v2.11](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.11) (unchanged) |
| netpack XIAO (for WiFi) | [elrs-netpack v2.10](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.10) or later (unchanged) |
| RotorHazard plugin (if used) | [vrxc_elrs v1.1.9](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.9) (unchanged) |

### Updating

v2.2.1's online update doesn't work because of this bug, so install this release once by one of these. From the next release on, the online update does it.

- **From the timer's page**: Settings → "⬆️ ファーム更新" → "ファイルから", pick `firmware.bin` and `littlefs.bin` from this release's zip (no USB).
- **Web flasher**: https://yanazoo.github.io/FPV-C5-Lap-Timer/ (Chrome / Edge on a PC, USB)
- **PlatformIO**:

```bash
git fetch && git checkout v2.2.2
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

Settings and pilots are kept.

### Verified

- On real hardware (XIAO ESP32-S3, client mode), "🔍 最新版を確認" succeeds and reads the latest release (v2.2.1).
- All PC tests pass; the S3, C5 and bridge builds were checked in CI.
- Writing the firmware and the web UI online ("⬇️ 更新") will be checked on hardware with the next release.
