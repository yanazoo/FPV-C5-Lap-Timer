# FPV C5 Lap Timer v2.3.2 — 「ELRSバックパック-ブリッジ」への表記の統一、XIAO C5 ブリッジの配線 / "ELRS Backpack bridge" wording, the XIAO C5 bridge's wiring

<a name="日本語"></a>

## 日本語

### 変更

- 「ESP-NOW ブリッジ」の呼び名を **「ELRSバックパック-ブリッジ」** に統一しました（README・UART 接続の手順書・Web 書き込みページ・設定画面の接続方式）。
- **XIAO ESP32-C5 のブリッジ**の書き込み方法・起動ログ・配線を、README と [docs/ELRS_UART_SETUP.md](https://github.com/yanazoo/FPV-C5-Lap-Timer/blob/main/docs/ELRS_UART_SETUP.md) に加えました。

| XIAO ESP32-S3（タイマー） | 向き | XIAO ESP32-C5（ブリッジ） |
|---|---|---|
| D6 / GPIO43（TX） | → | D7 / GPIO12（RX） |
| D7 / GPIO44（RX） | ← | D6 / GPIO11（TX） |
| GND | — | GND |

- 設定画面の接続方式の表示を「UART（ELRSバックパック-ブリッジに直結：XIAO C3 / C5 / Wrover）推奨」にしました。

### 対応するファームウェア

ファームの動作は v2.3.1 と同じです（変わったのは設定画面の表記だけ）。急いで更新する必要はありません。

### 動作確認

- PC テストと、すべてのビルド（タイマー・受信機・netpack・3 種のブリッジ）を CI で確認しました。

## English

### Changes

- The ESP-NOW bridge is now called **"ELRSバックパック-ブリッジ" / "ELRS Backpack bridge"** (README, the UART setup guide, the web flasher, the connection setting).
- The README and docs/ELRS_UART_SETUP.md add the **XIAO ESP32-C5 bridge**: how to write it, its boot log and wiring (D7 / GPIO12 RX ← timer TX, D6 / GPIO11 TX → timer RX, GND).

### Matching firmware

Works as v2.3.1 (only the settings screen's wording changed); no need to hurry the update.

### Verified

- PC tests and every build (timer, receiver, netpack, three bridges) in CI.
