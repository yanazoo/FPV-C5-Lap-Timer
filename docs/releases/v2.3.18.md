# FPV C5 Lap Timer v2.3.18 — パイロット別に周回・飛行時間と日付の切り替え / Pilot stats: laps, flying time and a day filter

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

### 追加

- **SD タブの「👤 パイロット別」に、次の列を足しました。**
  - **周回**：レースで数えたラップの合計
  - **飛行時間**：そのラップのタイムの合計（例 15:37.0、1 時間を超えると 1:02:03）
  - **平均ラップ**：飛行時間 ÷ 周回
  - いちばん下に、全員の周回と飛行時間の **合計** 行
  - ホールショットは周回・飛行時間に含みません。
- **「期間」のプルダウンで、日付ごとに集計できる**ようにしました。
  - 「すべての日」か、レースのあった日（新しい順、その日のレース数つき）を選べます。
  - 日付はタイマーの時計で記録したレースの開始時刻です（古いファイルは保存した時刻、どちらもないものは「日時不明」）。
  - 選んだ日だけで、出走・1 位・周回・飛行時間・平均・自己ベスト・最速ラップの推移を出します。
- スマホでは表が横にスクロールします（見出しが折り返さないように）。

### 対応するファームウェア

Web 画面だけの変更です。タイマー本体（S3）のファームと Web 画面を書き換えてください（「最新版を確認」から更新できます）。

### 動作確認

- PC テスト、ビルド、モック（16 レース・15 日分）で、全期間と日付を選んだときの集計を PC 幅とスマホ幅で確認しました。

## English

### Added

- **New columns in the SD tab's "👤 per pilot" table:**
  - **Laps**: the laps counted in races, in all
  - **Flying time**: those laps' times added up (e.g. 15:37.0; 1:02:03 past an hour)
  - **Average lap**: flying time ÷ laps
  - A **total** row with everyone's laps and flying time
  - The holeshot counts in neither.
- **A "period" drop-down to look at one day.**
  - "Every day", or one of the days with races (newest first, with the number of races).
  - The day is the race's start by the timer's clock (older files: when saved; neither: "date unknown").
  - Races, wins, laps, flying time, average, best and the best-lap trend are then for that day only.
- On phones the table scrolls sideways (headings no longer wrap).

### Matching firmware

Web UI change only. Update the timer (S3) firmware and web UI (from "check for update").

### Verified

- PC tests, the build, and the mock (16 races over 15 days): every day and one day, at PC and phone widths.
