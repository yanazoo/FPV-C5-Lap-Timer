# FPV C5 Lap Timer v2.3.17 — 広い画面でラップカードが画面いっぱいに / Lap cards fill wide screens

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 変更

- **PC などの広い画面（幅 1200px 以上）で、レース画面のラップカードが画面の幅いっぱいに並ぶ**ようにしました。
  - これまでは人数に関係なく画面の 1/8 の幅で、少ない人数だと中央に小さく並んでいました。
  - 今は人数で幅を分けます（4 人なら 1/4 ずつ）。1 人のときは画面の半分です。
  - カードが広くなると、名前・BEST・ラップタイムなどの文字も大きくなります（8 人のときは今までと同じ大きさ）。
- スマホやタブレットなど幅 1200px 未満の画面は今まで通りです。

### 対応するファームウェア

Web 画面だけの変更です。タイマー本体（S3）のファームと Web 画面を書き換えてください（「最新版を確認」から更新できます）。

### 動作確認

- PC テスト、ビルド、モックで幅 1632px・1250px（4 人）と 8 人相当の表示を確認しました。

## English

### Changes

- **On wide screens (1200 px and up), the race tab's lap cards now fill the width.**
  - Before, each card was an eighth of the window whatever the number of pilots, so a few pilots sat small in the middle.
  - The width is now shared by the pilots on cards (quarters for 4); one pilot gets half.
  - Wider cards get larger text (name, BEST, lap times); with 8 pilots it is the same size as before.
- Phones, tablets and windows under 1200 px are unchanged.

### Matching firmware

Web UI change only. Update the timer (S3) firmware and web UI (from "check for update").

### Verified

- PC tests, the build, and the mock at 1632 px and 1250 px (4 pilots) and as for 8 pilots.
