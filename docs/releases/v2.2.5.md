## 日本語

### 追加：取りこぼしたラップの追加（📈）

受信機がゲートの通過を取りこぼしたとき、あとから RSSI を見ながら、その通過をラップとして追加できるようにしました。

- タイマーはレース中、各チャンネルの RSSI を記録します（40 ms ごとの最大値、レースの時間で 30 分まで。一時停止中は記録しません。PSRAM に 720 KB）。
- レースカードの **📈**（ログイン中）を押すと、そのパイロットの RSSI がレースの時間に沿ったグラフで全画面に出ます。緑の線＝Enter、赤の線＝Exit、縦線＝数えた通過（HS／○周目）、点線＝レースの終わりです。
- **「次の候補 ▶」「◀ 前の候補」**：Exit の線を超えた山のうち、通過として数えられていないもの（取りこぼしの候補）に順に移ります。グラフをタップしても時刻を選べます（近くの山に合わせます）。
- **「＋ ここにラップを追加」**：選んだ時刻に通過を足します。その周を 2 つに分け、トータルタイムは変わりません。最後の通過より後なら、1 周増えます。ベストラップ・順位・総周回数の完走、全ブラウザ・ゴーグルの OSD・SD の記録に反映します。
- 数えた通過を選んだときは「この通過を削除」もできます（レースカードのラップ行をタップしたときと同じ削除です）。
- 追加・削除は、レースを**ストップしてからクリアするまで**の間にできます。クリアすると直した結果が SD に保存され、RSSI の記録は消えます。
- 「＋ / − / 全体」で拡大・縮小、グラフの左右ドラッグか下のスライダーで時間を動かせます。

### 更新方法

- **v2.2.4 のタイマー**：設定タブ「⬆️ ファーム更新」→「🔍 最新版を確認」→「⬇️ v2.2.5 に更新」。電源の入れ直しは要りません。
- **v2.2.3 以前**：[Web 書き込みページ](https://yanazoo.github.io/FPV-C5-Lap-Timer/) か PlatformIO で書き込んでください。

```bash
git fetch && git checkout v2.2.5
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

設定とパイロット情報は引き継がれます。

## English

### New: adding a missed lap (📈)

When the receiver missed a gate pass, the pass can now be added afterwards, looking at the RSSI.

- During a race the timer records every channel's RSSI: the highest reading of every 40 ms, up to 30 min of race time, not while paused (720 KB of PSRAM).
- **📈** on a race card (logged in) shows the pilot's RSSI over the race time, full screen. Green line: Enter. Red line: Exit. Vertical lines: the passes counted (HS / laps). Dotted line: the end of the race.
- **"次の候補 ▶" / "◀ 前の候補"** jump to the next / previous peak above Exit that isn't a counted pass (a pass the receiver may have missed). Tapping the chart picks a time too (snapped to the nearby peak).
- **"＋ ここにラップを追加"** adds a pass at that time. It splits that lap, so the total stays; after the last pass it adds a lap. The best lap, positions, finishing on the total laps, every browser, the goggle OSD and the SD record follow.
- On a counted pass, "この通過を削除" deletes it (the same delete as tapping a lap row on the race card).
- Adding and deleting work between **Stop and Clear**. Clear saves the race as corrected to SD and drops the RSSI record.
- "＋ / − / 全体" zoom in, out and to the whole race. Drag the chart sideways, or use the slider below it, to move in time.
