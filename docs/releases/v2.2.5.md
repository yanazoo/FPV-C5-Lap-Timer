## 日本語

### 追加：取りこぼしたラップの数え直し（RSSI ボタン）

受信機がゲートの通過を取りこぼしたとき、レースのあとで RSSI を見ながら入・出を合わせ、その値でラップを数え直せるようにしました。合わせた入・出はパイロット情報にも保存し、次のレースからその値で計測します。

- タイマーはレース中、各チャンネルの RSSI を記録します（40 ms ごとの最大値。一時停止中は記録しません）。
- **記録する長さは設定で選べます**（設定 →「RSSI の記録時間」：5・10・30 分・1・2・3・4 時間、初期値 30 分）。練習で何時間もクリアしない場合に長くできます。PSRAM を 1 時間あたり約 1.4 MB 使い、4 時間で約 5.8 MB です。
- レース中に RSSI の画面を開いているときは、記録の増えた分だけを 2 秒ごとに読みます（4 時間の記録は 1 人あたり 720 KB。最初に開くときに全部を読みます）。
- 記録時間に達すると、**レースを自動でストップ**し、全員の画面に知らせます。ラップは残り、数え直しもできますが、**そのレースは再開できません**（スタートボタン・ディレクターのスイッチ・マイクのスタートを受け付けません）。記録の後のラップが数え直しで消えないようにするためです。続けるときはクリアして（SD に保存）、新しくスタートします。
- レースカードの RSSI の行の **「RSSI」ボタン**（ログイン中）を押すと、そのパイロットの RSSI が**レース全体**のグラフで全画面に出ます。「🔍 詳細」でタップした所の近くを 20 秒に拡大し、「全体」で戻ります。
- 縦線＝今数えている通過（HS／○周目）、緑の線＝Enter（入）、赤の線＝Exit（出）、点線＝レースの終わりです。
- 取りこぼした山が数えられるように、**入・出の線を動かします**（数字・±1／±10 のボタン・グラフ上の線のドラッグ）。動かすたびに、その値で数えたときの通過を **▼ 黄色（増える通過）**・**✕ 赤（消える通過）**で示し、「今の計測 ○ 周 → この値だと ○ 周」と出します。
- **「この値で数え直す」**：記録した RSSI から、このパイロットのラップをその値で数え直します（クールダウン・総周回数・制限時間のルールもレースと同じ）。前から数えていた通過は元の時刻のまま、増えた通過だけ記録の時刻（40 ms 単位）になります。ベストラップ・順位・全ブラウザ・ゴーグルの OSD・SD の記録に反映します。
- **その入・出はパイロット情報（キャリブ）にも保存**し、次のレースからその値で計測します。「元の値」で今の値に戻せます。
- グラフの下に、その入・出で数えたときのラップの一覧（周・タイム・累計）を出します。**▼ 黄色**の周が、増える周です。
- グラフで数えている通過をタップすると、「選んだ通過を削除」もできます（レースカードのラップ行をタップしたときと同じ削除）。
- 数え直し・削除は、**レース中**でも、ストップしてからクリアするまでの間でもできます。レース中は記録を 2 秒ごとに読み直し、その時点までの記録で数え直します（ゲートを通過中の分は、そのままレースが数えます）。クリアすると直した結果が SD に保存され、RSSI の記録は消えます。
- レースカードの **+LAP** と **「RSSI」** は、同じ大きさ（56 × 20 px）のボタンにしました。

- **v2.2.4 のタイマー**：設定タブ「⬆️ ファーム更新」→「🔍 最新版を確認」→「⬇️ v2.2.5 に更新」。電源の入れ直しは要りません。
- **v2.2.3 以前**：[Web 書き込みページ](https://yanazoo.github.io/FPV-C5-Lap-Timer/) か PlatformIO で書き込んでください。

```bash
git fetch && git checkout v2.2.5
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

設定とパイロット情報は引き継がれます。

## English

### New: counting again for a missed lap ("RSSI" button)

When the receiver missed a gate pass, the Enter / Exit can be adjusted after the race, looking at the RSSI, and the laps counted again with them. The values are saved to the pilot, so the next race counts with them.

- During a race the timer records every channel's RSSI: the highest reading of every 40 ms, not while paused.
- **How long is a setting** (Settings → "RSSI の記録時間": 5, 10 or 30 min, 1, 2, 3 or 4 h; default 30 min), for practice sessions that go on for hours without a Clear. It takes about 1.4 MB of PSRAM an hour, about 5.8 MB for 4 h.
- While racing, the RSSI view fetches only what was added every 2 s (4 h is 720 KB a pilot; it is read whole when the view opens).
- When the record is full, **the race stops by itself** and every browser is told. The laps stay and can be counted again, but **that race can't be carried on**: Start (the button, the director's switch, the microphone) is refused, so no lap past the record's end could be lost to a count. Clear (saved to SD) and start a new race.
- The **"RSSI" button** at the end of a race card's RSSI row (logged in) shows the pilot's RSSI over the **whole race**, full screen. "🔍 詳細" zooms to 20 s around the point tapped; "全体" goes back.
- On the chart:
  - vertical lines: the passes counted now (HS / laps);
  - green line: Enter; red line: Exit;
  - dotted line: the end of the race.
- Move the Enter / Exit lines (numbers, ±1 / ±10 buttons, or drag them on the chart) until the missed peak counts.
  - As you go, the passes those values would give show as **▼ yellow (added)** and **✕ red (gone)**, with "今の計測 n 周 → この値だと m 周".
- **"この値で数え直す"** counts the pilot's laps again from the record with those values. The cooldown, total laps and time limit work as in the race.
  - Passes counted before keep their exact times; only the added ones take the record's (40 ms).
  - Best lap, positions, every browser, the goggle OSD and the SD record follow.
- **The values are saved to the pilot** (calibration), so the next race counts with them. "元の値" goes back to the pilot's current values.
- Under the chart, the laps those values give (lap, time, total); **▼ yellow** marks the laps that come in.
- Tap a counted pass on the chart to delete it ("選んだ通過を削除"), the same delete as a lap row.
- Counting again and deleting work **during a race** too, and between Stop and Clear.
  - While racing, the record is fetched again every 2 s and the count uses the record up to that moment; a pass still in the gate is left to the race.
  - Clear saves the race as corrected to SD and drops the RSSI record.
- **+LAP** and **"RSSI"** on a race card are now the same size (56 × 20 px).
