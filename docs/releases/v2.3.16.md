# FPV C5 Lap Timer v2.3.16 — iPhone で「レディ」が聞こえないことがあるのを修正 / "Ready" call on iPhone fixed

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 修正

- **iPhone の Safari で、スタートを押しても「レディ」を言わないことがありました。**
  - 原因：iPhone は画面をタップしたあとでないと読み上げができないため、タップのときに無音の言葉を一度読み上げて読み上げを有効にしています。画面ロックや別アプリから戻ると、これを次のタップ（スタートボタン）でやり直します。その無音の言葉を読んでいる最中に「レディ」を頼むと、iPhone がそれを捨ててしまうことがありました。
  - 今は、無音の言葉が終わるのを待ってから（最大 0.8 秒）「レディ」を言います。

### 対応するファームウェア

Web 画面だけの変更です。タイマー本体（S3）のファームと Web 画面を書き換えてください（「最新版を確認」から更新できます）。

### 動作確認

- PC テストとビルドを確認しました。iPhone での確認はまだです。

## English

### Fixes

- **On iPhone Safari, "レディ" (Ready) was sometimes not said after pressing Start.**
  - Cause: iPhone only speaks after a tap, so a tap says a silent word to unlock speech. Back from the lock screen or another app, the next tap (Start) does this again, and iPhone often dropped "レディ" asked for while the silent word was still being said.
  - "レディ" now waits for the silent word to finish (0.8 s at most).

### Matching firmware

Web UI change only. Update the timer (S3) firmware and web UI (from "check for update").

### Verified

- PC tests and the build. Not yet tested on an iPhone.
