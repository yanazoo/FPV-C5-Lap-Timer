# FPV C5 Lap Timer v2.3.16 — iPhone で「レディ」をときどき言わないのを修正 / "Ready" call on iPhone fixed

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 修正

- **iPhone の Safari で、スタートを押しても「レディ」をときどき言わないことがありました**（3-2-1 の音は鳴る）。
  - iPhone の読み上げは、前のレースのラップ読み上げが終わったことに気づかず「読み上げ中」のまま固まったり、頼まれた言葉を黙って捨てたりすることがあります。「レディ」はその後ろに並ぶか、捨てられて聞こえませんでした。
  - 今は iPhone では次のようにします。
    - 前の読み上げが残っていたら、それを打ち切ってから「レディ」を言います。
    - 0.35 秒たっても読み上げが始まらなければ、もう一度だけ言い直します（3-2-1 より前に間に合います）。
    - タップで読み上げを有効にする無音の言葉の最中なら、それが終わるのを待ちます（最大 0.8 秒）。

### 対応するファームウェア

Web 画面だけの変更です。タイマー本体（S3）のファームと Web 画面を書き換えてください（「最新版を確認」から更新できます）。

### 動作確認

- PC テストとビルドを確認しました。iPhone での確認はまだです。

## English

### Fixes

- **On iPhone Safari, "レディ" (Ready) was sometimes not said after Start** (the 3-2-1 tones were).
  - iPhone's speech can stay "speaking" after the last race's lap call has ended, or silently drop what it is asked to say; "レディ" queued behind it or was lost.
  - On iPhone now:
    - A call still left over is cut off before "レディ".
    - If nothing has started 0.35 s later, it is said once more (still before the 3-2-1).
    - During the silent word a tap says to unlock speech, it waits for that to end (0.8 s at most).

### Matching firmware

Web UI change only. Update the timer (S3) firmware and web UI (from "check for update").

### Verified

- PC tests and the build. Not yet tested on an iPhone.
