## 日本語

### 変更

- **Web 書き込みページ**（https://yanazoo.github.io/FPV-C5-Lap-Timer/）に、ブリッジなしで組んだ FPV C5 Lap Timer を **配線を変えずに** ELRS-NETpack にする「タイマー流用版」を追加しました（[ELRS-NETpack v2.3.2](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.2)）。
  - ELRS-NETpack：配線「通常 / **タイマー流用**」を選べます（S3 に書き込みます）。
  - ELRSバックパック-ブリッジ：ハードに「**XIAO ESP32-C5（タイマー流用）**」を追加しました（C5 に書き込みます）。
  - 配線はタイマーのまま（S3 D3/D4 ⇔ C5 D4/D5、5V 給電）。タイマーに戻すときは、S3 にタイマー、C5 に受信機を書き込みます。
- README：セットアップの「3. ELRSバックパック-ブリッジ」に、2 台目のタイマーを netpack にする方法を書きました。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.4 と同じです（書き換え不要）。

### 動作確認

- PC テストと、すべてのビルド（タイマー・受信機・netpack の通常版とタイマー流用版・ブリッジ 4 種）を確認しました。タイマー流用版の実機での確認をお願いします。

## English

### Changes

- The **web flasher** has the "timerwiring" build: an FPV C5 Lap Timer built without a bridge becomes an ELRS-NETpack **with no rewiring** ([ELRS-NETpack v2.3.2](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.2)).
  - ELRS-NETpack: wiring "standard / **timer's**" (written to the S3).
  - ELRS Backpack bridge: the board "**XIAO ESP32-C5 (timer's wiring)**" (written to the C5).
  - The timer's wiring stays (S3 D3/D4 ⇔ C5 D4/D5, 5V). Back to a timer: the timer to the S3, the receiver to the C5.
- README: setup step 3 tells how to make a second timer into a netpack.

### Matching firmware

The timer (S3) firmware is the same as v2.3.4 (no update needed).

### Verified

- PC tests and every build (timer, receiver, netpack standard and timerwiring, four bridges). Please check the timerwiring build on hardware.
