<a name="日本語"></a>

## 日本語

### 変更

- 画面上部の **CPU 温度**（S3 のチップ内の温度センサー）を、高い温度でも正確に測るようにしました。
  - これまでは Arduino の `temperatureRead()` が、センサーを **10〜50℃ 用**の設定で使っていました。チップは周りの空気より 10〜20℃ 以上高くなるため、80℃ 台の表示は誤差が大きくなっていました。
  - 今は **20〜100℃ 用**の設定で測ります（20℃ を下回るときは −10〜80℃ 用に自動で切り替えます）。
- CPU 温度の**色**：69℃ までは今まで通り（灰色）、**70〜84℃ は黄色**（置き場所・通気の見直しを）、**85℃ 以上は赤**（早めに冷やしてください）。マウスを乗せると理由が出ます。

### 対応するファームウェア

タイマー本体（S3）のファームと Web 画面を書き換えてください。受信機・netpack は変更ありません。

### 動作確認

- PC テストとビルドを確認しました。実機での表示の確認をお願いします。

## English

### Changes

- The **CPU temperature** in the header (the S3's internal sensor) is measured accurately at high temperatures too.
  - Arduino's `temperatureRead()` set the sensor for **10-50 C**; the chip runs 10-20 C or more above the air around it, and readings in the 80s came with a large error.
  - It is now read in the sensor's **20-100 C** range (below 20 C, its -10-80 C range, switched automatically).
- The CPU temperature's **colour**: up to 69 C as before (grey), **70-84 C yellow** (check the place and the airflow), **85 C and over red** (cool it down soon); the tooltip says why.

### Matching firmware

Update the timer (S3) firmware and web UI. The receiver and the netpack are unchanged.

### Verified

- PC tests and the build. Please check the reading on hardware.
