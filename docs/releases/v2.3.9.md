# FPV C5 Lap Timer v2.3.9 — RSSI の記録時間が「5 分」と表示される問題を修正 / The RSSI record length no longer shows "5 min"

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 修正

- **設定 → RSSI の記録時間**が、何に設定しても、画面を開き直すと「**5 分**」と表示されていました。
  - 原因：画面は、タイマーとつながったとき（WebSocket）に設定を受け取りますが、その中に RSSI の記録時間が入っていませんでした。画面の選択欄は受け取れなかったため、いつも一番上の「5 分」を表示していました。
  - **保存そのものはできていました**（「保存しました」のとおり、タイマーには設定した時間が入っています）。表示だけが間違っていました。
  - 今は、タイマーとつながったときと、設定を変えたとき（ほかのブラウザーにも）に記録時間を送ります。
- 「⚠ メモリーが足りないため、今は ○ 分まで記録します」の注意が、一度出ると消えず、また長い時間を選んだ直後（次のスタートまで）にも出ていました。今は、実際にメモリーが足りなかったときだけ出ます。

### 対応するファームウェア

タイマー本体（S3）のファームと Web 画面を書き換えてください。

### 動作確認

- PC テスト、ビルド、モックでの画面の確認（設定・タブ切り替え・別のブラウザー・注意の表示と消去）をしました。実機での確認をお願いします。

## English

### Fixes

- **Settings → RSSI record length** showed "**5 min**" whatever was set, once the page was opened again.
  - Cause: the page takes its settings when it connects to the timer (WebSocket), and the record length wasn't among them, so its select showed its first choice (5 min).
  - **Saving worked** (the timer had the length set); only the display was wrong.
  - The length now comes with the settings on connecting and on every change (to every browser).
- The "⚠ memory short: recording N min" note stayed once shown, and showed right after choosing a longer length (taken at the next start). It now shows only when PSRAM was really short.

### Matching firmware

Update the timer (S3) firmware and web UI.

### Verified

- PC tests, the build, and the page on the mock (setting, switching tabs, a second browser, the note shown and cleared). Please check on hardware.
