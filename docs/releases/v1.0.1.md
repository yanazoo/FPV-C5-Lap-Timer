## 日本語

### 変更：ゴーグル OSD の接続方式の初期値を「UART（ESP-NOW ブリッジ直結）」に

ゴーグル OSD の基本の構成は、**ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E）を S3 に UART で直結する方法**です。これに合わせて、初期値を変えました。

- 設定 → 🥽 ELRS OSD の「接続方式」の初期値を **UART** にしました
- 選択肢の並びも、UART（推奨）→ WiFi（elrs-netpack XIAO 経由）の順にしました
- 変わるのは、ELRS の設定をまだ保存していない本体（新しくセットアップした本体）の初期値だけです。**すでに保存済みの設定は、そのまま維持されます**

### ドキュメント

- ゴーグル OSD は **HDZero ゴーグル（ELRS バックパック搭載）のみ対応**であることを、README と手順書に明記しました
- ESP-NOW ブリッジの UART 直結を基本の構成（A）、WiFi 接続を次の手段（B）として、構成図・接続方法・セットアップ手順を並べ替えました

### 対応するファームウェア

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | このリリース |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（サブモジュール `e62a635`。v1.0.0 から変更なし） |
| ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E） | [elrs-netpack v2.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.6)（変更なし） |
| RotorHazard で使う場合のプラグイン | [vrxc_elrs v1.1.7](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.7)（変更なし） |

### 更新方法

v1.0.0 から更新する場合は、**S3 のファームウェアと Web UI** を書き込み直してください。C5 とブリッジは書き込み直す必要はありません。

```bash
git fetch && git checkout v1.0.1
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みバイナリも添付しています（`fpv-c5-lap-timer-v1.0.1-xiao_esp32s3.zip` など）。

- PC テストがすべて合格、S3・C5・ブリッジのビルドを CI で確認
- 初期値の変更は、モックサーバーで確認しました。実機での確認はこれからです

## English

### Changed: the goggle OSD connection defaults to UART (ESP-NOW bridge wired to the S3)

The base setup for the goggle OSD is the **ESP-NOW bridge (XIAO ESP32-C3 / Wrover-E) wired straight to the S3 over UART**, so it is now the default:

- Settings → 🥽 ELRS OSD → "Connection" defaults to **UART**
- the choices are listed UART (recommended) first, then WiFi (via the elrs-netpack XIAO)
- only units without saved ELRS settings (fresh installs) see the new default; **saved settings are kept**

### Documentation

- README and the setup guide state that the goggle OSD works with **HDZero goggles (with an ELRS backpack) only**
- the UART-wired ESP-NOW bridge is presented as the base setup (A), WiFi as the next choice (B), in the diagram, the wiring and the setup steps

### Matching firmware

| Device | Firmware |
|---|---|
| XIAO ESP32-S3 (timer) | this release |
| XIAO ESP32-C5 (receiver) | FPVGate C5MK (submodule `e62a635`, unchanged since v1.0.0) |
| ESP-NOW bridge (XIAO ESP32-C3 / Wrover-E) | [elrs-netpack v2.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.6) (unchanged) |
| RotorHazard plugin (if used) | [vrxc_elrs v1.1.7](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.7) (unchanged) |

### Updating

From v1.0.0, flash **the S3 firmware and the web UI** again; the C5 and the bridge need no reflash.

```bash
git fetch && git checkout v1.0.1
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

Prebuilt binaries are attached (`fpv-c5-lap-timer-v1.0.1-xiao_esp32s3.zip` and the others).
