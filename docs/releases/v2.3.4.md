# FPV C5 Lap Timer v2.3.4 — WiFi・MSP 接続の安定化、動作の軽量化 / Steadier WiFi and MSP link, lighter running

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 変更（安定性）

- **ELRS-NETpack との MSP 接続**
  - WiFi がいったん切れてつながり直したとき（クライアントモード、ELRS-NETpack のホストモードに接続中など）、古い接続を捨ててすぐにつなぎ直します（以前は次の送信で切れに気づき、さらに最大 5 秒待っていました）。
  - つなぎ直しの間隔を 5 秒から 2 秒にしました。WiFi がつながっていない間は試しません（OSD の処理を止めないため）。
  - 接続を待つ時間を 0.4 秒から 1.5 秒にしました。電波が弱いと 0.4 秒では、そこにいる netpack にもつながらないことがありました（自分のアクセスポイントで機器を順に試すときは 0.4 秒のまま）。
  - TCP キープアライブを 約 11 秒（5 秒＋2 秒×3）から 約 22 秒（10 秒＋3 秒×4）にしました。電波が弱いときに、確認が数回届かないだけで良い接続を切っていました。
- **WiFi（クライアントモード）**：接続する帯域幅を 20 MHz にしました（ELRS-NETpack のホストモードと同じ）。切れたときの理由をログに出します。

### 変更（軽量化）

- **RSSI の記録**：レースのスタート時に、記録用のメモリ（PSRAM、最大 5.8 MB）を一度に消していたのをやめ、記録しながら少しずつ消すようにしました。スタートの瞬間に Web サーバーと WiFi の処理が止まっていました。
- **RSSI の 10 Hz 送信**：管理者のブラウザが 1 台もないときは、送るデータを作りません。
- **Web 画面**：調整タブのグラフ描画の処理が、どのタブでも画面の更新ごとに動いていたのを、調整タブを開いている間だけにしました（スマホの負担を減らします）。

### 対応するファームウェア

タイマー本体（S3）のファームと Web 画面を書き換えてください。ELRS-NETpack をホストモードで使う場合は、**ELRS-NETpack v2.3.1** も合わせて書き換えてください。

### 動作確認

- PC テストとビルドを確認しました。実機での確認をお願いします。

<a name="english"></a>

## English

### Changes (stability)

- **MSP link to ELRS-NETpack**
  - When the WiFi link drops and comes back (client mode, e.g. on ELRS-NETpack's host WiFi), the old connection is dropped and a new one made at once (it used to be noticed at the next write, then up to 5 s more).
  - Retry every 2 s instead of 5 s; no attempt while the WiFi is not joined (the OSD isn't held up).
  - Connect timeout 1.5 s instead of 0.4 s: on a weak link 0.4 s missed a netpack that was there (0.4 s stays for trying each device on the timer's own access point).
  - TCP keepalive ~22 s (10 s + 3 × 4 s) instead of ~11 s: a few lost probes on a weak link dropped a good connection.
- **WiFi (client mode)**: 20 MHz wide (as ELRS-NETpack's host WiFi); the reason of a dropped link is logged.

### Changes (lighter)

- **RSSI record**: no longer cleared all at once at the start (up to 5.8 MB of PSRAM), which held up the web server and the WiFi for a moment; it is cleared as the race goes.
- **10 Hz RSSI telemetry**: not built when no admin browser is connected.
- **Web UI**: the calibration charts' drawing loop ran on every screen refresh on every tab; now only while the calibration tab is open.

### Matching firmware

Update the timer (S3) firmware and web UI. With ELRS-NETpack in host mode, also update it to **ELRS-NETpack v2.3.1**.

### Verified

- PC tests and builds. Please check on hardware.
