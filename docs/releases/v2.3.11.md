## 日本語

### 変更

- **Web 書き込みページ**（https://yanazoo.github.io/FPV-C5-Lap-Timer/）の「ELRS-NETpack（XIAO ESP32-S3）」（通常 / タイマー流用）が、**[ELRS-NETpack v2.3.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.6)** になりました。QR ページの上に、タイマーの画面の QR コードを **IP アドレス**で出します（`.local` を開けないスマホでも開けます）。RotorHazard がつながっているときは、RotorHazard の画面（ポート 5000、つながらなければ 80）の QR コードになります。下は ELRS-NETpack の WiFi の QR コードです。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.9 と同じです（書き換え不要）。netpack の XIAO を使う場合は、ELRS-NETpack v2.3.6 に書き換えてください（netpack の「更新」ページ、または Web 書き込みページ）。

### 動作確認

- PC テストと、すべてのビルド（タイマー・受信機・netpack の通常版とタイマー流用版・ブリッジ 4 種）を CI で確認しました。

## English

### Changes

- The web flasher's "ELRS-NETpack (XIAO ESP32-S3)" (standard / timer's wiring) is now **[ELRS-NETpack v2.3.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.6)**: the QR page shows the timer's page **by IP address** on top (for phones without `.local`), or RotorHazard's page when it is connected (port 5000, else 80); the netpack's WiFi below.

### Matching firmware

The timer (S3) firmware is the same as v2.3.9 (no update needed). With a netpack XIAO, update it to ELRS-NETpack v2.3.6.

### Verified

- PC tests and every build (timer, receiver, netpack standard and timerwiring, four bridges) in CI.
