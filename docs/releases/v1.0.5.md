## 日本語

### 変更：ストップ音を「下がる 3 音」に

ストップ音は、これまでスタート音と同じ「ポーー」でした。今回から「ポポポーン」と下がる 3 音にしたので、スタートとストップを聞き分けやすくなります。

- 三角波で 440 → 330 → 220Hz（ラ→ミ→ラ）と 1 オクターブ下がります。カウントダウンと同じ 440Hz から始まります
- 各音は 90ms、0.15 秒間隔です。最後の音は約 1 秒の余韻を残して消えます

### 変更：スタートボタンで「スタート」と読み上げ

iPhone の Safari では、ボタンを押したときにしか読み上げを始められません。そのため、スタートを押したときに読み上げを準備しています。この準備には音量 0 の空の文字を使っていましたが、端末によっては音量 0 が無視され、一瞬何かの声が出ていました。

- この準備を「スタート」という読み上げに変えました。読み上げを準備する働きはこれまでと同じです
- 音声設定に従います。音声 OFF のときや「ビープ音のみ」のときは読み上げません
- 一時停止からの再開（ストップ → スタート）では読み上げません

## English

### Changed: a falling three-note stop tone

The stop tone used to be the same "pooo" as the start tone. It is now a falling three-note "po-po-poon", so start and stop are easy to tell apart.

- Triangle wave, 440 → 330 → 220 Hz (A4 → E4 → A3): one octave down, starting from the countdown's 440 Hz
- 90 ms per note, 150 ms apart; the last note rings out for about 1 s

### Changed: Start says "スタート"

On iPhone Safari, speech can only begin from a button press, so pressing Start prepares speech for the race. This used to be done with an empty utterance at volume 0. Some speech engines ignore volume 0 and read the empty text out as a short noise.

- Start now says "スタート" instead, which prepares speech in the same way
- It follows the voice settings: nothing is said when voice is off or set to beeps only
- Nothing is said when resuming a paused race (Stop → Start)
