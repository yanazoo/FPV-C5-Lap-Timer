## 日本語

### Web 書き込みページ（https://yanazoo.github.io/FPV-C5-Lap-Timer/）

- **ファイルを指定して書き込む**：試験版・前の版など、手元の .bin（またはリリースの zip）を選んで書き込めます。
  - 機器（タイマー・受信機・ELRS Netpack・ESP-NOW ブリッジ）を選ぶと、書き込み先のアドレスがファイル名から自動で入ります（変更可）。タイマーの littlefs.bin（Web 画面）も入ります。
  - firmware.bin には「最初のアプリから起動」（otadata）を自動で付けます（ネットから更新したあとの機器でも、書いたファームで起動するように）。
  - 書き込み先の重なりの確認、つながった機器の種類の確認、「すべて消去」（初期値 OFF）、進み具合とログの表示。
- **ELRS Netpack（XIAO ESP32-S3）** を書き込めるようにしました（netpack の XIAO：elrs-netpack v2.2.x）。
- **ESP-NOW ブリッジ**を 1 つの欄にまとめ、ハード（**XIAO ESP32-C3 / XIAO ESP32-C5 / ESP32 Wrover-E**）を選んで書き込むようにしました。**XIAO ESP32-C5** のブリッジが新しく使えます（配線は XIAO C3 と同じ D7 / D6）。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.0 と同じです（書き換え不要）。

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | v2.3.0 と同じ |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（変更なし） |
| ESP-NOW ブリッジ（XIAO C3 / XIAO C5 / Wrover-E） | elrs-netpack（サブモジュール。C5 対応を追加。C3・Wrover-E は変更なし） |
| netpack XIAO（WiFi で使う場合） | elrs-netpack v2.2.0 以降 |

### 動作確認

- タイマー・受信機・netpack・3 種のブリッジのビルドと、Web 書き込みページの作成を CI で確認しました。
- ブラウザーで、ファイルを指定して書き込む部分（zip を分けてアドレスを入れる・タイマーの littlefs.bin・otadata を付ける・ハードの選択）を確かめました。
- 実機への書き込みは、これから確認します。

## English

### Web flasher (https://yanazoo.github.io/FPV-C5-Lap-Timer/)

- **Your own files** ("ファイルを指定して書き込む"): write .bin files of a test build or an older release, or a release zip.
  - Pick the device (timer, receiver, ELRS Netpack, ESP-NOW bridge); addresses come from the file names (editable), the timer's littlefs.bin (web UI) included.
  - A firmware.bin gets the otadata that starts the first app slot (so a device updated online starts what was written).
  - Overlap check, chip check, optional erase (off by default), progress and log.
- **ELRS Netpack (XIAO ESP32-S3)** can be written (the netpack XIAO, elrs-netpack v2.2.x).
- **ESP-NOW bridge**: one card with a board select (**XIAO ESP32-C3 / XIAO ESP32-C5 / ESP32 Wrover-E**). The **XIAO ESP32-C5** bridge is new (wired on D7 / D6 as the XIAO C3).

### Matching firmware

The timer (S3) firmware is the same as v2.3.0 (no update needed).

### Verified

- CI builds of the timer, receiver, netpack and the three bridges, and of the web flasher site.
- In a browser: the own-files part (zip split and addresses, the timer's littlefs.bin, otadata, board select).
- Writing on hardware: to be checked next.
