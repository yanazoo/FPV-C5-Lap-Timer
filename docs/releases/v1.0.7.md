## 日本語

### 新機能：順位表

- メインタイマーの下に、割り当て済みのパイロット全員の**最速ラップ・周回数・トータルタイム**を 1 つの表で表示します
- 並び順は設定の「順位の決め方」で選びます：**トータルタイム**／**最速ラップ**／**時間内の周回数**
- 1〜3 位は金・銀・銅の色、完走したパイロットには 🏁 を付けます

### 新機能：時間内の周回数レース

- 設定タブの一番上「🏁 レース内容」で、**制限時間**（30 秒〜30 分）と、時間切れ時の最終周を数えるかどうかを設定します。総周回数もこのカードに移しました
- タイマーは残り時間を表示します。時間切れ後は赤いマイナス表示になり、**ストップを押すまで**計り続けます。ゴーグルの OSD も同じです
- 残り 30 秒・20 秒で「残り○秒」、残り 10 秒からは 1 秒ごとに数を読み上げ、0 秒で**ファンファーレ**を鳴らします

### 改善：PC・スマホ・ゴーグルの表示がそろう

- **ブラウザ同士**：レース時間を本体の時計で数えるので、PC とスマホで時間がずれません。スタート・ストップ・クリアは全ブラウザに反映し、取りこぼしても 1 秒以内に直ります
- **ブラウザと OSD**：スタートボタンでもレースディレクターのスイッチでも、本体が「レディ → 3-2-1 → スタート」を進め、全ブラウザとゴーグルが同じタイミングで動きます
  - OSD にも 3・2・1 を表示します
  - ストップ時は、止まった時間を表示したまま残します
- **OSD の遅れ・秒飛び**：
  - レースクロックの更新は時計の行だけを送ります
  - ESP-NOW ブリッジを**コネクションレス送信**にしました（受信確認を待たず、各更新を 3 回送る）。電源の入っていないゴーグルや、同じバインドフレーズのゴーグルがあっても遅れません
  - ブリッジのファームウェアの書き換えが必要です

### 修正

- 入口・出口の通過音が、短い通過で鳴らないことがある
- OSD の表示が消えずに残ることがある
- レースディレクターのバインドフレーズでスタート・ストップできない
  - トグル（倒したままのスイッチ）とプッシュ（押しボタン、1 回押すだけ）の両方に対応しました
- パイロット情報や WiFi パスワードの変更で「パスワードを保存しますか？」が出る
- クリアが、周回 0 のときに他のブラウザへ反映されない

### その他

- レース画面の音声スイッチを「**音声テスト**」ボタンにし、スタート・ストップ・クリアと同じ行に並べました（音声の ON/OFF は設定タブ）
- Web UI を gzip で書き込み、読み込みを軽くしました。使っていない処理を削除しました
- 表示名「ディレクターバインドフレーズ（任意）」
- README：クライアントモードのルーターは 2.4GHz の**チャンネル 6〜11** を推奨します（ESP-NOW はチャンネル 1 固定）

### 更新方法

**タイマー（ファームウェアと Web UI の両方）**と、**ESP-NOW ブリッジ**を書き込み直してください。

```bash
git fetch && git checkout v1.0.7
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
# ブリッジ（XIAO C3 の場合。Wrover-E は -e esp32dev）
pio run -d third_party/elrs-netpack/elrs-espnow-bridge -e xiao_esp32c3 -t upload --upload-port COMx
```

ビルド済みのバイナリも添付しています。

- `fpv-c5-lap-timer-v1.0.7-xiao_esp32s3.zip`：タイマー（`littlefs.bin` が Web UI）
- `elrs-espnow-bridge-v1.0.7-*.zip`：ブリッジ

設定は引き継がれます。

### 動作確認

- PC テストはすべて合格し、S3・C5・ブリッジのビルドを CI で確認しました
  - OSD のテストを追加しました（3-2-1、ストップ時の時間、カウントダウンの秒、電波断）
- 2 台のブラウザで、スタート・ストップ・再開・クリア・カウントダウン中のストップがそろうことを確認しました
- 実機で確認しました
  - 時間内レースの読み上げとファンファーレ
  - レースディレクターのスイッチ（トグル・プッシュ）
  - 他のパイロットのゴーグルに OSD が混ざらないこと
  - 電源の入っていないゴーグルがあってもレースクロックが遅れないこと

## English

### New: ranking table

- Under the main timer, one table shows every assigned pilot's **best lap, laps and total time**
- The order follows the ranking setting: **total time**, **best lap**, or **laps within a time limit**
- Places 1–3 are gold, silver and bronze; a finished pilot gets 🏁

### New: laps within a time limit

- Set the **time limit** (30 s to 30 min) and whether the last lap after time-up counts, in **🏁 レース内容** at the top of the settings tab. Total laps moved to the same card
- The timer shows the time left. After time-up it shows the time over in red (minus) and keeps counting **until Stop**. The goggles' OSD does the same
- At 30 s and 20 s left it says "残り○秒"; from 10 s it counts down every second, and plays a **fanfare** at 0

### Improved: PC, phone and goggles stay in step

- **Between browsers**: the race clock runs on the timer's own clock, so PC and phone show the same time. Start, stop and clear reach every browser; a lost message is put right within a second
- **Browsers and OSD**: whether started from the button or the race director's switch, the timer runs "レディ → 3-2-1 → start", and every browser and goggle follow it
  - The OSD also shows 3, 2, 1
  - On stop it keeps the stopped time up
- **OSD lag and skipped seconds**:
  - Race-clock updates send only the clock row
  - The ESP-NOW bridge now sends **connectionless** (no ACK wait, each update sent 3 times). Goggles that are off, or two goggles on one bind phrase, no longer delay the OSD
  - Reflash the bridge

### Fixed

- Gate enter/exit tones sometimes missing on short passes
- OSD rows sometimes left on screen
- Start/stop from the race director's bind phrase not working
  - Both a toggle switch and a push button (one press) work
- Browsers offering to save a password when pilot data or the WiFi password changed
- Clear with no laps not reaching the other browsers

### Other

- The voice switch on the race tab is now a "**音声テスト**" (voice test) button in the Start / Stop / Clear row (voice on/off is in settings)
- The web UI is stored gzipped and loads faster; unused code was removed
- Label: "ディレクターバインドフレーズ（任意）"
- README: in client mode, put the router on 2.4 GHz **channel 6–11** (ESP-NOW is fixed to channel 1)
