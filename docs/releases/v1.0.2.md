## 日本語

### 修正：WiFi クライアントモードで画面が動かない

クライアントモード（ルーターに接続）で開くと、画面は出るのにタブが反応せず、パイロットも表示されないことがありました。

- クライアントモードでは WiFi の省電力（モデムスリープ）を止めました。無線が休む間にページの読み込みが詰まったり落ちたりしていました
- 画面のスクリプトを 1 つずつ順に読み込み、失敗したファイルは取り直すようにしました。それでも読めないときは「再読み込みしてください」と表示します

### 変更：複数のブラウザで常に同じ表示に

これまでは、ブラウザごとに表示がずれ、誰かがボタンを押したときだけ揃っていました。タイマー本体を正として、変更をすべてのブラウザへ知らせるようにしました。

- **クリア**：どのブラウザで押しても、全ブラウザでクリア
- **カウントダウン（3・2・1）**：全ブラウザに表示
- **途中から開いたブラウザ**：レース中に開いても、同じラップ表・ベスト・累計・経過時間を表示
- **レース設定**（計測モード・クールダウン・SD 記録・総周回数・ゲイン）：本体の値に統一し、保存すると全ブラウザに反映
- **キャリブの閾値・ELRS OSD 設定・ネットワーク設定**：保存すると他のブラウザにも反映（入力中のフォームは上書きしません）
- パイロットの割り当てを変えても、他のブラウザのラップ表が消えなくなりました
- 音声の ON/OFF・読み上げの設定は、端末ごとのままです

### 変更：レース画面のレイアウトとログイン

- パイロットカードを **PC では 8 列、スマホ横向きでは 4 列**、縦向きでは今までどおり 2 列で並べます。8 人未満のときは中央に寄せます
- レースタブでログインしても、設定タブに移らず**レースタブのまま**になります
- スマホを横向きにしてログインした後も、Safari のアドレスバー・タブバーが隠れるようにしました

### 対応するファームウェア

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | このリリース |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（サブモジュール `e62a635`。変更なし） |
| ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E） | [elrs-netpack v2.6](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.6)（変更なし） |
| RotorHazard で使う場合のプラグイン | [vrxc_elrs v1.1.7](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.7)（変更なし） |

### 更新方法

v1.0.1 から更新する場合は、**S3 のファームウェアと Web UI の両方**を書き込み直してください。C5 とブリッジは書き込み直す必要はありません。

```bash
git fetch && git checkout v1.0.2
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みバイナリも添付しています（`fpv-c5-lap-timer-v1.0.2-xiao_esp32s3.zip` など）。

## English

### Fixed: the web UI did not work in WiFi client mode

Opened over a router (client mode), the page showed but no tab responded and no pilots appeared.

- Modem sleep is off in client mode: the radio dozed and the page's script requests stalled or were dropped
- The scripts load one at a time and a failed file is fetched again; if one still fails, the page says to reload

### Changed: every browser shows the same race

Several browsers used to keep their own view and only lined up when a button was pressed. The timer is now the one source of truth and tells every browser about every change:

- **Clear** on any browser clears them all
- the **3-2-1 countdown** shows on every browser
- a browser **opened mid-race** shows the same laps, best lap, totals and race time
- **race settings** (lap mode, cooldown, SD log, total laps, gain) come from the timer and reach every browser when saved
- **calibration thresholds, ELRS OSD and network settings** saved on one browser update the others (not a form someone is typing in)
- reassigning pilots no longer wipes the lap tables on other browsers
- sound and voice settings stay per device

### Changed: race layout and login

- Pilot cards: **8 per row on a PC, 4 on a phone in landscape**, 2 in portrait as before; fewer than eight are centred
- Logging in on the race tab **stays on the race tab** instead of jumping to settings
- After logging in with the phone in landscape, Safari tucks its address and tab bars away again

### Updating

From v1.0.1, flash **both the S3 firmware and the web UI**; the C5 and the bridge need no reflash.

```bash
git fetch && git checkout v1.0.2
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

Prebuilt binaries are attached (`fpv-c5-lap-timer-v1.0.2-xiao_esp32s3.zip` and the others).
