# FPV C5 Lap Timer v2.3.8 — XIAO 以外の ESP32-S3・ESP32-C5 ボードにも書き込める / Boards other than the XIAO (ESP32-S3, ESP32-C5) on the web flasher

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

### 追加

- **受信機：ESP32-C5 汎用ボード・モジュール**（ESP32-C5-WROOM-1、Waveshare ESP32-C5-Zero など、フラッシュ 4MB 以上）。Web 書き込みページの受信機に「ハード：XIAO ESP32-C5 / **ESP32-C5 汎用ボード・モジュール**」を追加しました（FPVGate C5MK の汎用版 `c5zero`）。S3 とは **GPIO4（RX）・GPIO5（TX）**でつなぎます（リリースのファイルは `fpvgate-c5mk-…-esp32c5.zip`）。
- **ブリッジ：ESP32-C5 汎用ボード・モジュール**（GPIO4 RX / GPIO5 TX、[ELRS-NETpack v2.3.4](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.4)）。
- **タイマー・netpack：ESP32-S3 モジュール・ボード**（ESP32-S3-WROOM-1(U)-N16R8 など、PSRAM 8MB オクタル・フラッシュ 8MB 以上）にも、XIAO と同じファームを書き込めます。配線は XIAO と同じ GPIO 番号です（README と書き込みページに書きました）。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.7 と同じです（書き換え不要）。

### 動作確認

- PC テストと、すべてのビルド（汎用 C5 の受信機・ブリッジを含む）を CI で確認しました。ESP32-S3-WROOM-1U-N16R8・汎用 ESP32-C5 での実機確認をお願いします。

## English

### New

- **Receiver: generic ESP32-C5 boards and modules** (ESP32-C5-WROOM-1, Waveshare ESP32-C5-Zero and the like; 4 MB+ flash). The web flasher's receiver has "board: XIAO ESP32-C5 / **generic ESP32-C5**" (FPVGate C5MK's generic `c5zero` build), wired to the S3 on **GPIO4 (RX), GPIO5 (TX)** (release file `fpvgate-c5mk-…-esp32c5.zip`).
- **Bridge: generic ESP32-C5** (GPIO4 RX / GPIO5 TX, [ELRS-NETpack v2.3.4](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.4)).
- **Timer and netpack: ESP32-S3 modules and boards** (ESP32-S3-WROOM-1(U)-N16R8 and the like; 8 MB octal PSRAM, 8 MB+ flash) take the XIAO's firmware, wired by the same GPIO numbers (README, web flasher).

### Matching firmware

The timer (S3) firmware is the same as v2.3.7 (no update needed).

### Verified

- PC tests and every build (the generic C5 receiver and bridge included) in CI. Please check on an ESP32-S3-WROOM-1U-N16R8 and a generic ESP32-C5.
