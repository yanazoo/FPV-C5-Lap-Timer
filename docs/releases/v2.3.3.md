<a name="日本語"></a>

## 日本語

### 変更

- **Web 書き込みページ**（https://yanazoo.github.io/FPV-C5-Lap-Timer/）の「ELRS-NETpack（XIAO ESP32-S3）」が、**[ELRS-NETpack v2.3.0](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.0)** になりました。主な変更：
  - WiFi の接続先 5 件（自動／選択）・IP アドレスの固定
  - ホストモードの改良（PC の接続が速い、`fpv-c5-lt.local` で FPV C5 Lap Timer が開く、接続台数の設定、FPV C5 Lap Timer との接続切れの通知）
  - QR タブ（ELRS-NETpack の WiFi と FPV C5 Lap Timer の QR コード）、管理者ログイン（初期パスワード `admin`。変更してください）、モード切り替えの物理スイッチ
  - 設定ページの表示が速くなりました
- 名前の表記を「**ELRS-NETpack**」にそろえました（書き込みページ）。
- README：netpack の設定用 WiFi の名前を `ELRS-NETpack-Setup` に直しました。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.0 と同じです（書き換え不要）。netpack の XIAO を使う場合は、ELRS-NETpack v2.3.0 に書き換えてください（netpack の「更新」ページ、または Web 書き込みページ）。

### 動作確認

- PC テストと、すべてのビルド（タイマー・受信機・netpack・3 種のブリッジ）を CI で確認しました。
- ELRS-NETpack v2.3.0 は、FPV C5 Lap Timer と組み合わせて実機で確認しました。

## English

### Changes

- The web flasher's "ELRS-NETpack (XIAO ESP32-S3)" is now **[ELRS-NETpack v2.3.0](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.0)**: 5 client networks and a fixed address; host mode improvements (fast PC join, `fpv-c5-lt.local` opens FPV C5 Lap Timer, a device limit, a lost-connection notice); a QR tab, an admin login (default password `admin`: change it), a mode switch; faster settings pages.
- The name is written "**ELRS-NETpack**" (web flasher).
- README: the netpack's setup WiFi is `ELRS-NETpack-Setup`.

### Matching firmware

The timer (S3) firmware is the same as v2.3.0 (no update needed). With a netpack XIAO, update it to ELRS-NETpack v2.3.0.

### Verified

- PC tests and every build (timer, receiver, netpack, three bridges) in CI.
- ELRS-NETpack v2.3.0 was checked on hardware with FPV C5 Lap Timer.
