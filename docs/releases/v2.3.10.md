## 日本語

### 変更

- **Web 書き込みページ**（https://yanazoo.github.io/FPV-C5-Lap-Timer/）の「ELRS-NETpack（XIAO ESP32-S3）」（通常 / タイマー流用）が、**[ELRS-NETpack v2.3.5](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.5)** になりました。電圧ページに「**校正**」が付きました（テスターで測った電圧を入れると分圧比を計算して保存）。v2.3.4 の ESP32-C5 汎用ブリッジも含みます。

### 対応するファームウェア

タイマー本体（S3）のファームは v2.3.9 と同じです（書き換え不要）。netpack の XIAO を使う場合は、ELRS-NETpack v2.3.5 に書き換えてください（netpack の「更新」ページ、または Web 書き込みページ）。

### 動作確認

- PC テストと、すべてのビルド（タイマー・受信機・netpack の通常版とタイマー流用版・ブリッジ 4 種）を CI で確認しました。

## English

### Changes

- The web flasher's "ELRS-NETpack (XIAO ESP32-S3)" (standard / timer's wiring) is now **[ELRS-NETpack v2.3.5](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.3.5)**: the voltage page has "**校正**" (calibrate: the voltage measured with a meter sets the divider ratio); v2.3.4's generic ESP32-C5 bridge included.

### Matching firmware

The timer (S3) firmware is the same as v2.3.9 (no update needed). With a netpack XIAO, update it to ELRS-NETpack v2.3.5.

### Verified

- PC tests and every build (timer, receiver, netpack standard and timerwiring, four bridges) in CI.
