## 日本語

### 変更：効果音をすべて RotorHazard の合成トーンに

Web UI の効果音を、RotorHazard の合成トーン（MP3 を使わない設定のときの音）と同じ鳴り方にしました。

| 場面 | 音 |
|---|---|
| ゲートに入る | 矩形波 25ms ＋約 1 秒の余韻。**高さはチャンネルごと**（Ch1 440Hz から半音ずつ上がり Ch8 659Hz） |
| ゲートを出る | ノコギリ波 35ms を 2 回（同じくチャンネルごとの高さ） |
| ラップ・ベストラップ | **鳴らしません**。出の音と読み上げで知らせます |
| カウントダウン | 1 秒ごとに三角波 440Hz を 3 回 → スタートで三角波 880Hz を 0.7 秒 |
| ストップ | 三角波 880Hz を 0.7 秒（RotorHazard のレース終了音） |
| 完走（FINISHED） | 矩形波 1200／1800Hz を交互に 3 回（RotorHazard の勝者の音） |

- 以前の「ピロッ」というラップ音とベストラップのファンファーレは廃止しました。ラップはゲートを出た瞬間に記録されるため、出の音とラップ音が重なり、出の音が聞こえなくなっていました
- 音量のバランスも RotorHazard と同じです。レースの音（カウントダウン・スタート・終了）は通過音の 2 倍の大きさです
- RotorHazard の音声ファイルやコードは使っていません。波形・長さ・高さ・消え方を合わせて、ブラウザで合成しています

### 変更：ヘッダーの接続ランプを緑／赤に

ヘッダーの「C5」「OSD」に、それぞれランプを付けました。**緑が接続、赤が未接続**です。これまでは、どちらか一方が未接続だと両方が赤く見えていました。

### 更新方法

v1.0.3 から更新する場合は、**Web UI**だけを書き込み直してください（ファームウェアは変更なし）。

```bash
git fetch && git checkout v1.0.4
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みバイナリも添付しています（`fpv-c5-lap-timer-v1.0.4-xiao_esp32s3.zip` の `littlefs.bin` が Web UI です）。

## English

### Changed: every sound now matches RotorHazard's synthetic tones

| Moment | Sound |
|---|---|
| Entering the gate | square 25 ms with a ~1 s tail, **pitched per channel** (Ch1 440 Hz up in semitones to Ch8 659 Hz) |
| Leaving the gate | sawtooth 35 ms twice (same per-channel pitch) |
| Lap / best lap | **no tone**: the exit tone and the voice call mark it |
| Countdown | triangle 440 Hz each second three times, then triangle 880 Hz for 0.7 s at go |
| Stop | triangle 880 Hz for 0.7 s (RotorHazard's race-over tone) |
| Finish | square 1200 / 1800 Hz three times (RotorHazard's winner tone) |

- The old "piro" lap tone and best-lap fanfare are gone: a lap is recorded as the pilot leaves the gate, so they drowned out the exit tone
- Volumes keep RotorHazard's balance: race tones are twice the crossing beeps
- No RotorHazard audio files or code are used; the tones are synthesised in the browser to the same waveform, length, pitch and fade

### Changed: green / red status lamps in the header

"C5" and "OSD" each have their own lamp: **green when connected, red when not**. Before, one link down made both look red.
