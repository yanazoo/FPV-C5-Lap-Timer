# FPV C5 Lap Timer v2.3.15 — エラーによる再起動の記録を消せるように / Crash count can be cleared

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 追加

- **設定タブ「再起動」の「⚠ エラーによる再起動」に「記録を消す」ボタン**を付けました（管理者のみ）。
  - 回数は電源を切っても残るため、これまでは全消去で書き直すまで消せませんでした。
  - 消したあとにまた表示が出たら、それ以降に新しく起きたエラーです。

### 対応するファームウェア

タイマー本体（S3）のファームと Web 画面の両方を書き換えてください。

### 動作確認

- PC テスト、ビルド、モックでのボタン操作（表示 → 記録を消す → 表示が消える）を確認しました。実機での確認はまだです。

---

<a name="english"></a>

## English

### Added

- **A "clear" button next to "⚠ restarts after an error"** in the settings tab's restart card (admins only).
  - The count survives power cuts, so before it went only with a full erase and reflash.
  - If it shows again after clearing, a new error has happened since.

### Matching firmware

Update both the timer (S3) firmware and the web UI.

### Verified

- PC tests, the build, and the button on the mock (shown → clear → gone). Not yet tested on hardware.
