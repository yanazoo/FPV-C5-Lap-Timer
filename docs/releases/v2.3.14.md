# FPV C5 Lap Timer v2.3.14 — 同梱の ELRS-NETpack を v2.3.8 に更新 / Bundled ELRS-NETpack v2.3.8

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

### 変更

- **同梱の ELRS-NETpack を v2.3.8 に更新**しました。
  - お知らせ音（ブザー・LED）が重なって早口の「ピピピ」になる問題を修正（前の音が終わってから次を鳴らします）。
  - USB テザリングを削除。
  - 設定画面のラジオボタン・チェックボックスの大きさを統一（iPhone などで大きさがそろいます）。
- Web 書き込みページの netpack の説明から USB テザリングを外しました。
- タイマー本体の中身は v2.3.13 と同じです。

### 対応するファームウェア

タイマー本体（S3）は書き換え不要です。ネットパックは Web 書き込みページ、またはネットパックの画面のオンライン更新で v2.3.8 にしてください。

### 動作確認

- CI でビルドを確認しました。実機での確認はまだです。

<a name="english"></a>

## English

### Changes

- **The bundled ELRS-NETpack is now v2.3.8.**
  - Beeps (buzzer / LED) no longer run together into a fast "beep-beep-beep": each waits for the one before to finish.
  - USB tethering removed.
  - Radio buttons and tick boxes are one size (iPhone and others).
- The web flasher's netpack card no longer mentions USB tethering.
- The timer itself is the same as v2.3.13.

### Matching firmware

The timer (S3) does not need reflashing. Update the netpack to v2.3.8 from the web flasher or the netpack's online update.

### Verified

- Build checked in CI. Not yet tested on hardware.
