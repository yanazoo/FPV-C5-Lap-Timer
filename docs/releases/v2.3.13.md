# FPV C5 Lap Timer v2.3.13 — SD カードのフォーマットを修正 / SD card format fixed

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

### 修正

- **SD タブのフォーマット**で、パスワードを入れるとタイマーが再起動し、戻ってもフォーマットされていませんでした。
  - 原因：全ファイルの削除を Web の要求の中で行っていたため、ファイルが多いと時間がかかり、その処理の見張り（ウォッチドッグ）がタイマーを再起動していました。
  - 今は、削除を別の処理として裏で行います。押すとすぐ「フォーマットしています…」と出て、終わると「フォーマットしました（○ 件削除）」と知らせます（ほかのブラウザーにも）。
  - フォーマット中は、ほかの SD の操作（ファイル一覧など）をすぐ「使用中」で返します（待たせると同じ再起動が起きるため）。

### 対応するファームウェア

タイマー本体（S3）のファームと Web 画面を書き換えてください。

### 動作確認

- PC テスト、ビルド、モックでのフォーマットの流れ（パスワード → フォーマット中 → 完了・ファイル 0 件）を確認しました。

## English

### Fixes

- **Format on the SD tab** restarted the timer after the password, and the card came back unformatted.
  - Cause: deleting every file ran in the web request; with many files it took long enough for that task's watchdog to restart the timer.
  - It now runs in the background: the page says "formatting…" at once and reports "formatted (N deleted)" when done (to every browser).
  - While formatting, every other SD call (the file list and so on) answers "busy" at once (waiting would set off the same watchdog).

### Matching firmware

Update the timer (S3) firmware and web UI.

### Verified

- PC tests, the build, and the format flow on the mock (password → formatting → done, 0 files).
