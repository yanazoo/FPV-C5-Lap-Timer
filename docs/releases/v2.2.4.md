# FPV C5 Lap Timer v2.2.4 — 更新後の再起動で新しいファームが動かない不具合の修正 / Fix: the new firmware didn't start after an update's restart

> **Language / 言語:** [日本語](#日本語) | [English](#english)

---

<a name="日本語"></a>

## 日本語

### 修正

- **画面から更新したあと、再起動しても古いファームのまま動く**：タイマーの再起動は「2 秒間ディープスリープしてから起き直す」作りですが、ESP32 はディープスリープから起きるとき、前回と同じ場所のファームを起動します。そのため、更新で書き込んだ新しいファームは電源を入れ直すまで動かず、システム情報に「ファームと Web 画面のビルドが違います」と出ていました。新しいファームが書き込まれているときは、ディープスリープではなくリセットで再起動するようにしました（ネットから・ファイルからの両方、更新のあとに「タイマーを再起動」を押した場合も）。

### 対応するファームウェア

v2.2.3 から、受信機とブリッジは変わりません。

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | このリリース |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（サブモジュール `e62a635`。変更なし） |
| ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E） | [elrs-netpack v2.11](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.11)（変更なし） |
| netpack XIAO（WiFi で使う場合） | [elrs-netpack v2.10](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.10) 以降（変更なし） |
| RotorHazard で使う場合のプラグイン | [vrxc_elrs v1.1.9](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.9)（変更なし） |

### 更新方法

- **v2.2.2 / v2.2.3 のタイマー**：設定タブ「⬆️ ファーム更新」→「🔍 最新版を確認」→「⬇️ v2.2.4 に更新」。**今回だけは**、更新後の再起動を古いファームが行うため、再起動のあとシステム情報が v2.2.4 にならなければ、**電源を一度入れ直してください**。次の版からは入れ直し不要です。
- **v2.2.1 以前のタイマー**：[Web 書き込みページ](https://yanazoo.github.io/FPV-C5-Lap-Timer/) か PlatformIO、またはタイマー画面の「ファイルから」で `firmware.bin` と `littlefs.bin` を 1 つずつ書き込んでください（書き込んだあと電源を入れ直してください）。

```bash
git fetch && git checkout v2.2.4
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

設定とパイロット情報は引き継がれます。

### 動作確認

- 実機（XIAO ESP32-S3）で、v2.2.2 → v2.2.3 のネットからの更新（ファームと Web 画面のダウンロード・書き込み）が成功し、電源を入れ直すと v2.2.3 で動くことを確かめました。このときの「再起動では古いファームのまま」が今回の修正の対象です。
- PC テストはすべて合格し、S3・C5・ブリッジのビルドを CI で確認しました。
- 更新後に自動の再起動だけで新しいファームが動くことは、次の版への更新で実機で確かめます。

<a name="english"></a>

## English

### Fixed

- **After an update from the page, the timer restarted into the old firmware**: the timer restarts by sleeping 2 s in deep sleep, and the ESP32, waking from deep sleep, starts the same app it ran before. The new firmware only ran after a power cycle, and the system info said the firmware and web UI builds differ. When a new firmware has been written, the timer now restarts with a reset instead (online and from files, and also when "タイマーを再起動" is pressed after an update).

### Matching firmware

The receiver and the bridge are unchanged from v2.2.3.

| Device | Firmware |
|---|---|
| XIAO ESP32-S3 (timer) | this release |
| XIAO ESP32-C5 (receiver) | FPVGate C5MK (submodule `e62a635`, unchanged) |
| ESP-NOW bridge (XIAO ESP32-C3 / Wrover-E) | [elrs-netpack v2.11](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.11) (unchanged) |
| netpack XIAO (for WiFi) | [elrs-netpack v2.10](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.10) or later (unchanged) |
| RotorHazard plugin (if used) | [vrxc_elrs v1.1.9](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.9) (unchanged) |

### Updating

- **A v2.2.2 / v2.2.3 timer**: Settings → "⬆️ ファーム更新" → "🔍 最新版を確認" → "⬇️ v2.2.4 に更新". **This once**, the restart after the update is still done by the old firmware: if the system info doesn't show v2.2.4 after it, **power the timer off and on**. Later updates don't need that.
- **v2.2.1 or older**: use the [web flasher](https://yanazoo.github.io/FPV-C5-Lap-Timer/), PlatformIO, or "from files" on the timer's page with `firmware.bin` and `littlefs.bin` one at a time (then power-cycle).

```bash
git fetch && git checkout v2.2.4
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload
pio run -e xiao_esp32s3 -t uploadfs
```

Settings and pilots are kept.

### Verified

- On hardware (XIAO ESP32-S3): the online update v2.2.2 → v2.2.3 (downloading and writing the firmware and web UI) succeeded, and after a power cycle the timer ran v2.2.3. That the restart alone kept the old firmware is what this release fixes.
- All PC tests pass; the S3, C5 and bridge builds were checked in CI.
- That the automatic restart alone starts the new firmware is checked on hardware with the update to the next release.
