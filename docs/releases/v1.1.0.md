# FPV C5 Lap Timer v1.1.0 — SD カードのレース結果を見返す（PC 表示の改善）/ Race results on the SD card, better on a PC

> **Language / 言語:** [日本語](#日本語) | [English](#english)

<a name="日本語"></a>

## 日本語

v1.0.10 で追加した「SD カードで過去のレースを見返す」機能を、PC でも見やすくしました。この機能がそろったので、バージョンを 1.1.0 にしました。

### 改善：PC でグラフが画面からはみ出す

- **原因**：グラフは、スマホ用の大きさ（340×170）の図を画面の幅まで拡大していました。PC では高さが 500px を超え、数字や「1周」などの文字も大きくなっていました。
- **修正**：
  - グラフを、表示する幅に合わせて描くようにしました。
  - 幅の広い画面では、高さ 230px の横長になります。スマホでは今までと同じ大きさです。
  - 文字は拡大されなくなりました。
  - ウィンドウの大きさを変えたり、スマホを横にしたりすると、開いているグラフを描き直します。パイロット別の推移グラフも同じです。
- 1366×768 のノート PC でも、グラフと安定度の表が 1 画面に収まります。

### 改善：SD タブのボタン

- 「👤 パイロット別」と更新ボタンを同じ大きさにしました。更新ボタンには「🔄 更新」と文字を付けました。
- 「⚠ その他の操作」（フォーマット）は折りたたまず、常に表示します。ボタンは小さいまま「📁 ファイル」の一番下にあり、押したあとに管理者パスワードの入力が必要なのも変わりません。

### SD カードで見返せること（v1.0.10 から）

- **📜 レース結果**：新しい順の一覧です。レースをタップすると「結果」（順位表とラップ表）と「グラフ」（ラップタイムの推移と安定度）を表示します。
- **👤 パイロット別**：全レースを集計して、自己ベストと最速ラップの推移を表示します。読み込む前に、件数とかかる時間の目安を表示します。
- レースの日時と設定を記録し、ファイル名にも日時が入ります（`race_012_20261108_1432.csv`）。
- 「上書き」モードでは、日時が一番古いものから消します。番号は 999 の次は 000 です。

詳しくは [v1.0.10 のリリースノート](https://github.com/yanazoo/FPV-C5-Lap-Timer/releases/tag/v1.0.10)と README を参照してください。

### その他

- CI：ビルドの準備で、ビルドツールの部品を GitHub からダウンロードするときに失敗して止まることがありました。同じ部品を PyPI から先に入れるようにしました（`tools/ci_penv.sh`）。ファームウェアの中身には関係ありません。

### 対応するファームウェア

| 機器 | ファームウェア |
|---|---|
| XIAO ESP32-S3（タイマー） | このリリース |
| XIAO ESP32-C5（受信機） | FPVGate C5MK（サブモジュール `e62a635`。変更なし） |
| ESP-NOW ブリッジ（XIAO ESP32-C3 / Wrover-E） | [elrs-netpack v2.9](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.9)（変更なし） |
| netpack XIAO（WiFi で使う場合） | [elrs-netpack v2.7](https://github.com/yanazoo/elrs-netpack/releases/tag/v2.7) 以降（変更なし） |
| RotorHazard で使う場合のプラグイン | [vrxc_elrs v1.1.8](https://github.com/yanazoo/vrxc_elrs/releases/tag/v1.1.8)（変更なし） |

### 更新方法

- **v1.0.10 から更新する場合**：変わったのは Web UI だけなので、`uploadfs` だけで済みます。
- **それより前のバージョンから更新する場合**：タイマーのファームウェアと Web UI の両方を書き込んでください。

```bash
git fetch && git checkout v1.1.0
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload      # v1.0.10 からなら不要
pio run -e xiao_esp32s3 -t uploadfs
```

ビルド済みのバイナリも添付しています。設定は引き継がれます。

### 動作確認

- PC テストはすべて合格し、S3・C5・ブリッジのビルドを CI で確認しました。
- ブラウザーで確認しました：PC（1280×900）、ノート PC（1366×768）、スマホ（390×844）でのグラフの大きさ、ウィンドウの大きさを変えたときの描き直し、ボタンの大きさ。
- 実機で確認しました：SD タブの表示。

## English

The SD-card race viewer added in v1.0.10 now looks right on a PC too. With it complete, the version moves to 1.1.0.

### Improved: the graph no longer overflows a PC screen

- **Cause**: the graph was a phone-sized chart (340×170) stretched to the screen's width. On a PC it was over 500 px tall, with large numbers and lap labels.
- **Fix**:
  - The graph is drawn for the width it gets.
  - On a wide screen it is a 230 px tall wide chart; on a phone it is the same size as before.
  - The text is no longer scaled up.
  - Open graphs (a race's graph, a pilot's trend) are redrawn when the window size changes or a phone is turned.
- On a 1366×768 laptop the graph and the consistency table fit on one screen.

### Improved: the SD tab's buttons

- "👤 パイロット別" (per pilot) and the refresh button are the same size; refresh now reads "🔄 更新".
- "⚠ その他の操作" (format) is always shown instead of folded. The button is still small, at the bottom of "📁 ファイル", and still asks for the admin password.

### What the SD viewer does (since v1.0.10)

- **📜 Race results**: newest first. Tap a race for results (ranking and lap table) or a graph (lap times and consistency).
- **👤 Per pilot**: totals over every race, with personal bests and the best-lap trend. It first shows how many files it will read and about how long that takes.
- The race's date and rules are recorded, and file names include the date (`race_012_20261108_1432.csv`).
- Rotate mode deletes the race with the oldest date; numbers go 000–999 and start again.

See the [v1.0.10 release notes](https://github.com/yanazoo/FPV-C5-Lap-Timer/releases/tag/v1.0.10) and the README.

### Other

- CI: builds could stop when a build-tool package failed to download from GitHub. The same package is now installed from PyPI first (`tools/ci_penv.sh`). This does not change the firmware.

### Updating

- **From v1.0.10**: only the web UI changed; `uploadfs` is enough.
- **From an earlier version**: flash the timer's firmware and web UI.

```bash
git fetch && git checkout v1.1.0
git submodule update --init --recursive
pio run -e xiao_esp32s3 -t upload      # not needed from v1.0.10
pio run -e xiao_esp32s3 -t uploadfs
```

Prebuilt binaries are attached. Settings are kept.

### Verified

- All PC tests pass; the S3, C5 and bridge builds were checked in CI.
- In a browser: the graph's size on a PC (1280×900), a laptop (1366×768) and a phone (390×844); redrawing on a window resize; the button sizes.
- On real hardware: the SD tab.
