FPV C5 Lap Timer 書き込み

リリース
使い方
  • PC の Chrome または Edge で開きます（iPhone・Safari・Firefox では使えません）。
  • 機器を USB で PC につなぎ、書き込みたい機器の「書き込む」を押して、表示されるポートを選びます。
  • つながらないときは、機器の BOOT ボタンを押したまま RESET を押す（または USB を挿し直す）と書き込みモードになります。
  • 「デバイスを消去する（Erase device）」にチェックを入れると、WiFi・パスワード・パイロット情報などの設定がすべて消えます。ふだんの更新ではチェックしないでください。
  • タイマーは、クライアントモードでインターネットにつながっていれば、設定タブの「ファーム更新」からも更新できます（USB 不要）。

タイマー（XIAO ESP32-S3）

ファームと Web 画面の両方を書き込みます。

このブラウザーでは書き込めません。PC の Chrome / Edge で開いてください。 https で開いてください。

受信機（XIAO ESP32-C5・FPVGate C5MK）

VTX の電波を測る受信機です。

このブラウザーでは書き込めません。

ELRS-NETpack（XIAO ESP32-S3）

WiFi 接続で使う場合の netpack の XIAO（TCP の中継・Web 設定画面・ホストモード・USB テザリング）。

このブラウザーでは書き込めません。

ELRSバックパック-ブリッジ

ゴーグル OSD・送信機のリンクの読み取りに使います（elrs-netpack）。使っているボードを選んでください。

このブラウザーでは書き込めません。

ファイルを指定して書き込む

試験版・前の版など、手元の .bin（またはリリースの zip）を書き込みます（タイマーは firmware.bin と littlefs.bin の両方を）。ファイル名から書き込み先のアドレスを決めます（変更できます）。
